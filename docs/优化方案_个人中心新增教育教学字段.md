# 优化方案 — 个人中心新增教育教学模块字段

> 日期：2026-07-01
> 目标页面：`personal-center.html`
> 参考数据源：旧平台 `api/JiaoShi/DropdownData` + `docs/字典枚举值_来自旧平台.md`
> 适用范围：**全部教师类型**（事业编 / 控制数 / 合同制）

---

## 一、现状分析

### 1.1 当前已展示的字段

**个人信息卡片（renderProfileCard）**
- 姓名、性别、民族、出生年月、政治面貌、学历、毕业院校、学校、岗位等级(当前岗位)、职称(现任职务)、身份证号

**编辑弹窗 — 只读区（来源于人事档案）**
- 姓名、性别、民族、出生年月、身份证号、学历、毕业院校、单位名称、编制类型、岗位类别、岗位等级、岗位名称、任职时间、入编方式

**编辑弹窗 — 可编辑区**
- 政治面貌（下拉）、手机号、邮箱

**编辑弹窗 — 其他模块**
- 附件（身份证、证件照、学历学位证书）、家庭信息、证书信息

### 1.2 教师类型差异分析

| 对比维度 | 事业编/控制数教师 | 合同制教师 |
|----------|-------------------|------------|
| 示范账号 | 陈明辉 | 赵老师 |
| 编制类型 | 事业编 / 控制数 | 合同制 |
| 入编记录 | ✅ 有（含教育背景、岗位信息） | ❌ 无入编记录 |
| 岗位晋升 | ✅ 支持 | ❌ 不适用 |
| 标签页 | 编制信息 / 岗位信息 / 聘用信息 / 人事信息 / 登录历史 | 合同与聘用 / 人事信息 / 登录历史 |
| 编辑弹窗只读区 | 显示：岗位类别、岗位等级、岗位名称、任职时间、入编方式 | 显示：部分字段为 "—" |
| **新增字段需求** | ✅ 全部 10 个字段 | ✅ 全部 10 个字段（与事业编一致） |

> **结论**：合同制教师同样需要职务、职称、学历、学位、教育教学信息。区别仅在于：
> - 事业编教师的学历、学位可从入编记录中提取默认值
> - 合同制教师的学历、学位、教育教学信息完全来自用户自行填写（userProfile）

### 1.3 与旧平台的字段缺口

| 旧平台字段 | 新平台现状 | 类型 | 事业编 | 合同制 |
|------------|-----------|------|--------|--------|
| 职务 (job) | ❌ 未展示、不可编辑 | 下拉 | 需新增 | 需新增 |
| 职称 (title) | ❌ 仅从 promote 推导，不可编辑 | 下拉 | 需新增 | 需新增 |
| 学历 (education) | ⚠️ 仅展示为只读 | 下拉 | 需可编辑 | 需新增 |
| 学位 (degree) | ❌ 完全没有 | 下拉 | 需新增 | 需新增 |
| 初次任教时间 | ❌ 完全没有 | 日期 | 需新增 | 需新增 |
| 主要任教学段 | ❌ 完全没有 | 下拉 | 需新增 | 需新增 |
| 其他任教学段 | ❌ 完全没有 | 下拉(多选) | 需新增 | 需新增 |
| 主要任教学科 | ❌ 完全没有 | 下拉 | 需新增 | 需新增 |
| 其他任教学科 | ❌ 完全没有 | 下拉(多选) | 需新增 | 需新增 |
| 汉语言水平 | ❌ 完全没有 | 下拉 | 需新增 | 需新增 |

**枚举值（10项）**：
```
博士、硕士、本科、专科、高中、初中、职高、中专、技校、其他
```

**默认值逻辑**：
- 事业编：优先取 `userProfile.education`，否则取入编记录中的 education
- 合同制：优先取 `userProfile.education`，否则为空（待用户填写）

### 2.4 学位 (degree) — 下拉框（全新字段）

**枚举值（5项）**：
```
名誉博士、博士、硕士、学士、无
```

### 2.5 教育教学模块（6个新字段）

> 注："教师角色 (teacherRole)"字段在旧平台 `DropdownData` 中有返回，但新平台个人中心暂不需要此字段。

这些字段在编辑弹窗中组成独立区块 **"📖 教育教学信息"**。

#### 2.5.1 初次任教时间 (firstTeachingTime) — 日期选择
- 类型：`<input type="date">`
- 必填：否

#### 2.5.2 主要任教学段 (period) — 下拉框
**枚举值（12项）**：幼儿园、小学、初中、高中、特殊教育、中职、高职、成人中学、成人中等专业学校、高职大专、普通本科高校、其他

#### 2.5.3 其他任教学段 (secPeriod) — 多选下拉
- 枚举值：同上
- 与主要任教学段互斥（已选为主要的不出现在其他中）

#### 2.5.4 主要任教学科 (subject) — 下拉框
**枚举值（74项）**：学前教育、语文、数学、英语、美术、音乐…（详见旧平台字典）

#### 2.5.5 其他任教学科 (secSubject) — 多选下拉
- 枚举值：同上
- 与主要任教学科互斥

#### 2.5.6 汉语言水平 (chineseLevel) — 下拉框
**枚举值（24项）**：普通话一级甲等 ~ HSK十一级、MHK各级别、未测试

```javascript
  "job": "专任教师",
  "title": "一级教师",
  "education": "硕士研究生",
  "degree": "硕士",

  // 新增：教育教学信息
  "teachingInfo": {
    "firstTeachingTime": "2011-09",
    "mainPeriod": "初中",
    "secPeriods": ["高中"],
    "mainSubject": "语文",
    "secSubjects": ["道德与法治", "书法"],
    "chineseLevel": "普通话二级甲等"
```

### 4.2 buildProfile 函数改动

```javascript
// 从 user profile 合并新字段（两类教师通用）
if (up.job) p.job = up.job;
if (up.title) p.title = up.title;
if (up.education) p.education = up.education;
if (up.degree) p.degree = up.degree;
```
