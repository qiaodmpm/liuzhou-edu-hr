# 优化方案：待提交学校提醒功能

> 日期：2026-06-15 | 状态：方案确认中，暂未实施

---

## 一、需求

- 待提交列表展示所辖区内所有未提交台账的学校
- 每个学校每天允许提醒提交 **1 次**
- 管理员点击"提醒提交"→ 发送提醒（toast 提示 + 记录提醒时间）

---

## 二、"待提交"范围

当前"待提交"筛选匹配 `!submittedAt`（未提交）。需扩展为包括：

| 状态 | 说明 |
|------|------|
| 台账数据不存在 | 学校从未创建过台账（不在 `org_ledger` 中） |
| `submittedAt` 为空 | 学校已创建台账，但从未提交 |

> 11 所内置学校加上可能存在的未创建台账的学校，都应在"待提交"列表中展示。

---

## 三、待提交独立列表

当切换到"待提交"标签时，列表换为专属列结构（不同于其他标签的 13 列大表）：

```
┌─ 列表卡片 ───────────────────────────────────────────┐
│  学校编号      │学校名称  │所属区域 │最近提醒 │操作     │
│  gxlj-08-001  │柳州市八中│鱼峰区   │06-14   │提醒提交 │
│  gxlj-08-002  │柳州市十三中│鱼峰区 │06-15   │已提醒   │
│  —            │鱼峰区机关幼儿园│鱼峰区│—      │提醒建立 │
└──────────────────────────────────────────────────────┘
```

### 3.2 列定义

| 列 | 宽度 | 说明 |
|------|:--:|------|
| 学校编号 | 100px | `gxlj-08-001` |
| 学校名称 | 160px | — |
| 所属区域 | 80px | 市直属/鱼峰区/城中区... |
| 最近提醒 | 80px | `lastRemindDate`，未提醒过显示"—" |
| 操作 | 80px | 仅"提醒提交"/"已提醒"/"提醒建立" |

### 3.3 提醒按钮状态

| 今日是否已提醒 | 按钮文案 | 样式 |
|:--:|------|------|
| 台账存在 + 未提醒 | 提醒提交 | 蓝色链接，可点击 |
| 台账存在 + 已提醒 | 已提醒(今天) | 灰色文字，不可点击 |
| 台账不存在 | 提醒建立 | 蓝色链接，可点击 |

> 待提交列表操作区**不显示"查看"按钮**（未提交的台账无内容可查看）。

### 3.3 提醒逻辑

```javascript
// 台账数据新增字段
ledger.lastRemindDate: '2026-06-15'  // 最近一次提醒日期

// 提醒函数
function remindSchool(schoolName) {
  var d = allLedgers[schoolName];
  var today = new Date().toISOString().split('T')[0];
  
  if (d.lastRemindDate === today) {
    showToast('今日已提醒过该学校，请明天再试', 'warning');
    return;
  }
  
  d.lastRemindDate = today;
  saveLedgers();
  showToast('已提醒 ' + schoolName + ' 提交台账', 'success');
  renderList(); // 刷新按钮状态
}
```

### 3.4 次日重置

`lastRemindDate` 与当天日期比较，隔天自动认为未提醒。无需定时任务。

## 四、未建立台账的学校

当前 11 所内置学校均有台账数据。但理论上存在"不在此列表中的学校"。这部分学校需要额外处理：

```javascript
var REGISTERED_SCHOOLS = [
  '柳州市第一中学','柳州市第二中学','柳州高级中学','柳州市民族高中',
  '柳州市第八中学','柳州铁一中学','柳州市第十三中学','柳州市第二十五中学',
  '鱼峰区实验小学','柳州市特色实验高中','鱼峰区机关幼儿园'
];

// 待提交列表 = 未提交的台账 + 不在台账中但属于辖区的学校
```

未建立的学校显示"未建立"状态，操作为"提醒建立"（灰色不可点击或同样限频）。
