# 登录与注册 — 功能点详细方案

> 关联文档：`产品设计方案_柳州教育人事管理平台.md` 第 2.3 节「账号体系」

---

## 1. 账号模型总览

### 1.1 四类用户、三种账号创建路径

| 角色 | 谁来创建账号 | 唯一标识 | 登录方式 |
|------|------------|---------|---------|
| 教师 | 校级管理员（批量导入或单个创建） | 身份证号 / 教职工编号 | 用户名 + 密码 |
| 校管理员 | 区级管理员（区属）或市级管理员（市直属） | 手机号 | 手机号 + 密码 / 短信验证码 |
| 区管理员 | 市级管理员 | 手机号 | 手机号 + 密码 / 短信验证码 |
| 市管理员 | 系统初始化 / 上级管理员 | 手机号 | 手机号 + 密码 / 短信验证码 |

### 1.2 账号状态生命周期

```
待激活 ──→ 正常 ──→ 停用 ──→ 已注销
              │
              └──→ 锁定（多次密码错误/安全风险）
```

- **待激活**：管理员创建账号后，账号尚未完成首次登录
- **正常**：首次登录成功，密码已修改
- **停用**：管理员手动停用（如教师离职出编后）
- **锁定**：连续 5 次密码错误自动锁定 30 分钟，或管理员手动锁定
- **已注销**：账号物理删除前软删除标记（数据保留，不可登录）

## 2. 账号创建（注册）

> 本系统不开放公开注册。所有账号由上级管理员创建，杜绝虚假账号。

### 2.1 教师账号创建

**操作人**：校级管理员

**创建方式**：

| 方式 | 适用场景 |
|------|---------|
| 单个创建 | 零星新教师入职 |
| 批量导入 | 公开招聘批次入职（Excel 模板导入） |
| 系统对接同步 | 从全国教师管理信息系统同步教师基础信息 |

**单个创建流程**：

```
校管理员填写教师信息
  ├── 姓名
  ├── 身份证号（唯一标识，自动校验格式）
  ├── 教职工编号（唯一标识，可手动输入或系统自动生成规则）
  ├── 所属学校（自动带入当前管理员所属学校，不可修改）
  ├── 初始密码（系统随机生成 8 位，含大小写字母+数字）
  └── 手机号（选填，用于密码找回）
        │
        ▼
  提交 → 账号创建成功，状态 = 待激活
        │
        ▼
  系统展示初始密码（仅此一次可见，提示管理员抄送教师）
  同时支持「复制密码」「下载密码函（PDF）」供线下分发
```

**批量导入流程**：

```
校管理员下载 Excel 导入模板
  └── 模板列：姓名、身份证号、教职工编号、手机号（选填）

校管理员上传填写好的 Excel
        │
        ▼
  系统逐行校验
  ├── 身份证号格式 + 唯一性（与库内已有不重复）
  ├── 教职工编号唯一性
  ├── 必填字段非空
  └── 非法行标记红色，给出错误原因
        │
        ▼
  校验通过 → 确认导入
        │
        ▼
  批量创建账号，每个账号生成独立随机初始密码
        │
        ▼
  系统生成「导入结果清单」
  ├── 成功数 / 失败数
  └── 支持「导出密码函（PDF）」——按姓名→身份证号→初始密码列表，供管理员打印后分发
```

**约束规则**：
- 同一身份证号在系统中只能存在一个有效教师账号
- 教师账号与学校绑定，教师调校需走调动流程变更所属机构，不可重复创建
- 初始密码为一次性密码，教师首次登录必须修改后才能进入系统

### 2.2 管理员账号创建

**操作人**：
- 市管理员账号：系统初始化时由开发/运维团队通过脚本创建，或由已有市管理员创建
- 区管理员账号：市管理员创建
- 校管理员账号：区管理员（区属学校）或市管理员（市直属学校）创建

**创建流程**：

```
上级管理员填写
  ├── 姓名
  ├── 手机号（唯一标识，必填）
  ├── 所属机构（区教育局 / 学校）
  ├── 角色（区管理员 / 校管理员）
  └── 初始密码（系统随机生成）

        │
        ▼
  提交 → 账号创建成功，状态 = 待激活
        │
        ▼
  初始密码通过以下方式之一传递：
  ├── 界面展示（仅一次）
  └── 短信发送至绑定手机号（平台自动发送）
```

**约束规则**：
- 一个手机号只能绑定一个管理员账号
- 市管理员数量建议控制在 3-5 个
- 每个区教育局默认配置 1-2 个区管理员账号
- 每个学校默认配置 1 个校管理员账号，可按需增设

### 2.3 系统对接同步

与全国教师管理信息系统对接时：

- **匹配规则**：以身份证号为关联键
- **同步策略**：增量同步（每日/每周定时拉取变更数据）
- **冲突处理**：以外部系统为权威源更新基本信息（姓名、学历等），但账号密码、角色权限以本系统为准
- **同步内容**：仅同步教师基本信息，不同步账号密码和审批数据

## 3. 登录

### 3.1 登录方式总览

| 登录方式 | 适用角色 | 说明 |
|---------|---------|------|
| 身份证号 + 密码 | 教师 | 默认登录方式 |
| 教职工编号 + 密码 | 教师 | 备选登录方式 |
| 手机号 + 密码 | 管理员 | 默认登录方式 |
| 手机号 + 短信验证码 | 管理员 | 免密快捷登录 |

### 3.2 教师登录流程

```
教师访问系统 → 登录页
  │
  ├── 输入 身份证号 / 教职工编号
  ├── 输入 密码
  ├── 输入 图形验证码（连续 3 次登录失败后出现）
  └── 点击「登录」
        │
        ▼
  系统校验
  ├── 账号是否存在且状态非「已注销」
  ├── 账号是否被锁定（锁定剩余时间提示）
  ├── 账号是否被停用（提示联系管理员）
  ├── 密码是否正确
  └── 失败计数 +1
        │
        ▼
  校验通过 → 判断账号状态
  ├── 状态 = 待激活 → 强制跳转「首次登录修改密码」页
  └── 状态 = 正常 → 进入系统，跳转角色对应首页
```

**图形验证码规则**：
- 连续 3 次密码错误后触发，之后每次登录都需输入
- 登录成功后重置错误计数和验证码要求
- 同一账号连续 5 次错误 → 账号自动锁定 30 分钟
- 锁定期间即使输入正确密码也不可登录，提示剩余解锁时间

### 3.3 管理员登录流程

```
管理员访问系统 → 登录页
  │
  ├── 选择登录方式（密码登录 / 短信验证码登录）
  │
  ├── 方式A：手机号 + 密码
  │   ├── 输入手机号
  │   ├── 输入密码
  │   └── 与教师登录相同的校验 + 锁定逻辑
  │
  └── 方式B：手机号 + 短信验证码
      ├── 输入手机号
      ├── 点击「获取验证码」
      ├── 图形验证码校验（防刷）
      ├── 输入 6 位短信验证码
      └── 点击「登录」
            │
            ▼
      验证码校验（5 分钟内有效，最多尝试 3 次）
      通过 → 直接进入系统（跳过密码校验）
            若账号为「待激活」→ 仍需强制修改密码
```

**短信验证码规则**：
- 同一手机号 60 秒内只能发送 1 次
- 同一手机号每天最多发送 10 次
- 验证码 5 分钟内有效，最多尝试验证 3 次
- 验证码为 6 位纯数字

### 3.4 首次登录强制修改密码

> 适用于所有角色，账号状态为「待激活」时触发。

```
首次登录 → 系统拦截，跳转修改密码页
  │
  ├── 显示提示：首次登录请修改密码
  ├── 输入 初始密码（即管理员下发的密码）
  ├── 输入 新密码
  ├── 确认 新密码
  └── 点击「确认修改」
        │
        ▼
  校验：
  ├── 初始密码是否正确
  ├── 新密码 ≠ 初始密码
  ├── 新密码与确认密码一致
  └── 新密码复杂度满足要求
        │
        ▼
  修改成功 →
  ├── 账号状态：待激活 → 正常
  ├── 记录首次登录时间、IP
  └── 自动跳转角色对应首页
```

**密码复杂度要求**：
- 长度 8-20 位
- 必须包含大写字母、小写字母、数字三类字符
- 不得包含连续 3 位以上相同字符（如 aaa）
- 不得包含身份证号后 6 位或手机号片段
- 不得为常见弱密码（123456、password 等，系统内置黑名单）

### 3.5 多端登录与会话策略

| 端 | 会话策略 |
|---|---------|
| Web PC 端（管理员） | 单点登录：同一账号新登录会踢掉旧会话，旧端提示「账号在其他设备登录」 |
| Web PC 端（教师） | 与管理员相同，单点登录 |
| 微信小程序 / H5（教师） | 与 PC 端独立会话，允许 PC + 手机同时在线 |
| 全局 | 无操作 30 分钟后会话自动过期，需重新登录 |

## 4. 密码管理

### 4.1 忘记密码 — 教师

```
登录页 → 点击「忘记密码」
  │
  ├── 输入 身份证号 / 教职工编号
  ├── 输入 已绑定的手机号（创建账号时若未填写则无法使用此功能）
  └── 获取短信验证码
        │
        ▼
  验证码校验通过 → 进入重置密码页
  ├── 输入新密码
  ├── 确认新密码
  └── 提交 → 密码修改成功，跳转登录页

若未绑定手机号：
  └── 提示「请联系学校管理员重置密码」
```

### 4.2 忘记密码 — 管理员

```
登录页 → 点击「忘记密码」
  │
  ├── 输入 手机号
  └── 获取短信验证码
        │
        ▼
  验证码校验通过 → 进入重置密码页 → 设置新密码 → 完成
```

### 4.3 管理员重置密码（面向他人）

**操作人**：上级管理员

```
管理员进入「系统设置 → 账号管理」
  ├── 找到目标账号
  └── 点击「重置密码」
        │
        ▼
  确认操作 →
  ├── 系统生成新随机密码
  ├── 目标账号状态强制切为「待激活」（下次登录需改密码）
  ├── 旧密码立即失效
  └── 新密码通过以下方式传递：
      ├── 操作者界面展示（仅一次）
      └── 若账号绑定了手机号，短信发送新密码
```

**权限约束**：
- 市管理员可重置全市所有账号
- 区管理员可重置本辖区及下属学校账号
- 校管理员可重置本校教师账号
- 不可重置同级或上级管理员密码

### 4.4 主动修改密码

```
登录后 → 个人中心 → 修改密码
  ├── 输入 旧密码
  ├── 输入 新密码
  ├── 确认 新密码
  └── 提交
        │
        ▼
  校验旧密码正确 + 新密码复杂度 → 修改成功
  修改成功后不强制重新登录
```

### 4.5 密码过期策略

| 角色 | 密码有效期 | 过期前提醒 |
|------|----------|-----------|
| 管理员 | 90 天 | 过期前 7 天每次登录提醒 |
| 教师 | 180 天 | 过期前 14 天每次登录提醒 |

密码过期后登录 → 强制跳转修改密码页（与首次登录修改流程相同，但不需输入旧密码）。

## 5. 安全设计

### 5.1 传输与存储

| 环节 | 措施 |
|------|------|
| 传输 | 全站 HTTPS，密码和短信验证码接口额外做证书固定 |
| 存储 | 密码使用 bcrypt / argon2 加盐哈希，不可逆 |
| 日志 | 密码明文和短信验证码不出现在任何日志中 |

### 5.2 防攻击措施

| 攻击类型 | 防护措施 |
|---------|---------|
| 暴力破解 | 连续 5 次错误锁定 30 分钟；图形验证码递增触发 |
| 短信轰炸 | 同一手机号 60s 间隔 + 每天 10 次上限；发送前需图形验证码 |
| 会话劫持 | token 绑定 IP 变动检测（跨 IP 使用时需重新验证） |
| CSRF | 登录和敏感操作接口校验 CSRF token |
| XSS | 前端统一输出编码，CSP 头配置 |

### 5.3 操作审计日志

以下事件须记录审计日志：

| 事件 | 记录内容 |
|------|---------|
| 登录成功 | 账号、IP、设备指纹、时间 |
| 登录失败 | 账号、IP、失败原因、时间、连续失败次数 |
| 密码修改 | 账号、操作来源（自助/管理员重置/首次登录）、IP、时间 |
| 账号创建 | 操作人、被创建账号、角色、IP、时间 |
| 账号停用/启用 | 操作人、目标账号、操作、IP、时间 |
| 短信发送 | 手机号、发送场景（登录/找回密码）、IP、时间 |

## 6. 页面清单

| 页面 | 关键元素 |
|------|---------|
| 登录页 | 账号输入、密码输入、图形验证码、忘记密码入口、登录按钮、角色切换 tab（教师/管理员） |
| 首次登录修改密码 | 初始密码、新密码、确认新密码、密码规则提示 |
| 忘记密码页 | 身份验证（手机号/身份证号）、短信验证码、新密码设置 |
| 账号管理列表（管理员端） | 搜索、筛选（角色/机构/状态）、创建账号按钮、批量导入按钮、重置密码操作 |
| 创建账号弹窗 | 账号信息表单、角色选择、机构选择 |
| 批量导入页 | 模板下载、文件上传、校验结果展示、确认导入 |
| 个人中心-修改密码 | 旧密码、新密码、确认新密码 |

## 7. 异常场景处理

| 场景 | 处理方式 |
|------|---------|
| 教师出编后 | 校管理员手动停用其账号（或出编审批通过后自动停用） |
| 教师调校 | 由目标学校管理员发起调动流程，审批通过后教师账号归属机构变更，密码不变 |
| 管理员离职 | 上级管理员停用其账号，确保至少保留 1 个有效管理员 |
| 短信服务故障 | 管理员短信登录降级为密码登录；忘记密码降级为联系上级管理员重置 |
| 初始密码泄露 | 教师应在首次登录后立即修改；管理员可在账号管理中强制重置密码 |
