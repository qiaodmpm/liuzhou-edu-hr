# 优化方案：新建台账附件上传

**版本**: v1.0  
**日期**: 2026-06-25  
**状态**: 已覆盖（无需额外改动）

---

## 一、现状

提交弹框（含附件上传区）为新建台账和再次申报共用，**新建台账上传附件已支持**。

```
新建台账：编辑 → 提交审核 → 弹框（含附件）→ 确认提交
再次申报：编辑 → 提交审核 → 弹框（含附件）→ 确认提交
          ↑ 同一个弹框，同一套逻辑
```

## 二、可选优化（差异化体验）

如果希望区分"新建"和"再次申报"的提交体验，可考虑：

### 2.1 弹框标题和文案

| 场景 | 当前 | 建议 |
|------|------|------|
| 新建 | 提交审核 | **首次提交申报** |
| 再次申报 | 提交审核 | **再次提交申报** |
| 新建-变更区 | 本次变更内容（全显示"新增"） | **申报内容**（不标 old→new，直接列值） |
| 新建-原因 | 修改原因 | **申报说明** |

### 2.2 实现

`submitLedger` 中判断 `!ledger.submittedAt` 区分新建/再次申报，动态调整弹框文案：

```js
var isNew = !ledger.submittedAt;
title.textContent = isNew ? '首次提交申报' : '再次提交申报';
changesLabel = isNew ? '申报内容' : '本次变更内容';
reasonLabel = isNew ? '申报说明' : '修改原因';
```

### 2.3 diff 展示

新建时变更内容不显示箭头格式（`0 → 72`），改为直接展示：

```
📋 申报内容
▪ 核定事业编数：72
▪ 实有在编人数：68
▪ 厅级·核定职数：5
```

## 三、结论

- **附件上传**：已覆盖，新建和再次申报共用同一弹框，无需额外改动
- **文案优化**：上述差异化方案可选，改动量约 10 行
