一、模块概述
1.1 模块定位

系统基础模块是柳州教育人事管理平台的入口层基础设施，承载用户身份认证（JWT 登录态）、角色路由、工作台门户、个人信息管理、密码安全等核心基础能力。所有业务模块（编制申请、入编、出编、岗位设置等）均依赖本模块提供的认证令牌和角色信息。

本模块在总纲排期中为 P0 第一位，是所有其他模块的前置依赖。

1.2 业务背景

平台面向市/区/校三级管理员 + 教师 + 系统管理员共 5 类角色，需要统一的身份认证入口和角色感知的工作门户。核心场景：

  • 新旧平台共用账号体系：旧平台（lzjs.eduyunx.com）存量账号保留。新增账号在新平台创建后同步至旧平台，管理员权限各自独立维护
  • 首次登录初始化：新创建账号或管理员重置密码后，用户首次登录须完成强制改密 + 强制编辑个人信息（补充缺失字段）方可进入系统。校管理员首次登录还须额外编辑并提交学校信息审核
  • 角色切换须重新登录：一个账号可拥有多个角色，但不支持侧边栏热切换。切换角色须退出登录，回到登录页重新选择角色后登录
  • JWT 无状态认证：正式版采用 JWT Token 方案，Token 有效期 8 小时，支持 Refresh Token 续期
1.3 核心价值

🔐 统一身份入口

5 类角色通过同一登录页进入，角色选择决定后续菜单和权限

📊 角色感知工作台

登录后展示角色专属待办提醒、快捷操作、通知消息；不同角色看到不同内容

👤 个人信息中心

可查看和编辑基本信息、教育教学信息、证书信息、家庭信息

🔑 密码安全

支持忘记密码找回（短信验证）、首次登录强制改密、密码强度实时校验

📌 正式版与 Demo 版的关键差异：
① 无侧边栏角色切换器，切换角色须退出登录重新登录；
② 认证方案为 JWT + Refresh Token（8h + 7d），不再使用 localStorage 明文存储密码；
③ 首次登录需完成初始化向导：改密 → 补全个人信息 →（校管理员）提交学校信息审核；
④ 短信验证码对接真实 SMS 网关，不再使用固定验证码；
⑤ 操作日志写入后端数据库，不可篡改。

F01 — 登录认证
F01.01 角色选择 + 账号密码登录 P0
适用角色
全部 5 类角色（未登录状态）
触发条件
访问 index.html（登录页），无有效 JWT Token（JWT 令牌）
前置条件
账号已在系统管理模块创建且状态为"正常"
后置条件
登录成功 → 前端存储 JWT Token（JWT 令牌）+ Refresh Token（刷新令牌），跳转 workbench.html（工作台）。首次登录 → 跳转 personal-center.html?mode=init（个人中心·初始化向导）
核心业务规则
1. 角色标签页 5 选 1（系统/市/区/校/教师），默认"校管理员"
2. 账号为手机号或系统分配的用户名
3. 后端校验账号存在、密码正确、账号未被锁定
4. 连续 5 次密码错误 → 账号锁定 30 分钟。30 分钟后系统自动解锁，失败计数清零
5. 登录成功返回 JWT Token（JWT 令牌，有效期 8h）+ Refresh Token（刷新令牌，有效期 7d）
6. 记录登录日志（成功/失败、IP、设备信息）
产品交互规则
1. 切换角色标签页时更新账号输入框 placeholder
2. 密码输入框支持"显示/隐藏"切换（眼睛图标）
3. 点击"登录"按钮后显示 loading 状态（按钮文字变为"登录中..."+ 不可点击）
4. 登录失败 toast 提示错误信息，输入框不自动清空
5. 账号锁定后 toast 提示"账号已被锁定，请30分钟后再试"
F01.02 Token 自动续期 P1
适用角色
全部已登录角色
触发条件
JWT Token（JWT 令牌）过期（8h），Refresh Token（刷新令牌）仍有效（7d）
前置条件
已登录，持有有效 Refresh Token（刷新令牌）
后置条件
前端自动获取新 JWT Token（JWT 令牌），用户无感知
核心业务规则
1. 请求拦截器检测到 401（未授权）→ 自动调用 /api/auth/refresh（刷新令牌接口）
2. Refresh Token 过期 → 跳转登录页，提示"登录已过期，请重新登录"
3. 续期后使用新 Token 重放原请求
产品交互规则
1. Token 续期过程中页面正常展示，无 loading 遮罩
2. 续期失败跳转登录页时 toast 提示原因

十一、验收标准
11.1 功能完成的判定标准
  1. 登录页：5 个角色标签可切换，账号密码登录成功获取 JWT Token 并跳转工作台；密码错误有提示；连续 5 次错误锁定 30 分钟
  2. 忘记密码：3 步流程完整可走通（确认身份→短信验证→重置），重置成功后跳转登录页，可用新密码登录
  3. 首次登录初始化：needInit=true 的用户登录后进入 3 步初始化向导（改密 → 补全个人信息 → [校管理员]提交学校信息），每步不可跳过，完成后正常使用
  4. 工作台：根据角色正确展示待办统计和快捷入口；通知铃铛正确展示消息列表；待办数据正确过滤权限范围
  5. 个人中心：全部标签页内容正确展示；编辑弹框可保存并刷新；修改密码流程完整含强度校验；编制/岗位/聘用/合同标签页未补录时显示引导文案"请联系校管理员补录"
  6. 账号管理补录：校管理员可在编辑弹框中补录教师的编制/岗位/聘用/合同信息，保存后个人中心对应标签页立即生效
  7. 路由守卫：未登录无法通过 URL 访问内部页面；needInit 时仅可访问个人中心初始化向导
  8. Token 续期：JWT 过期后自动使用 Refresh Token 续期，用户无感知
  9. 退出再登录切换角色：退出后 Token 失效，重新选择角色登录后权限和菜单正确更新
