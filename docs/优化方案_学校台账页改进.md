## 一-补、汇总卡片改为双轨分组布局

### 问题

6 张扁平卡片，事业编和控制数的指标交叉排列，视觉上割裂，无法快速对比两条线的状态。

### 方案

改为双卡布局：左卡「事业编制」+ 右卡「控制数」，每卡内聚合所属指标 + 环形图。

```
┌─ 事业编制 ───────────────────┐  ┌─ 控制数 ─────────────────────┐
│                              │  │                              │
│   ◯ 91%                     │  │   ◯ 88%                     │
│   (环形图)                    │  │   (环形图)                    │
│                              │  │                              │
│   核定编制数        88 人     │  │   核定控制数         16 人    │
│   实有在编人数      80 人     │  │   实有控制数人数     14 人    │
│   空缺编制           8 人     │  │   空缺控制数          2 人    │
│   已批复计划数       5 人     │  │   已批复控制数        3 人    │
│   已使用计划数       4 人     │  │   已使用控制数        1 人    │
│   未使用计划数       1 人     │  │   未使用控制数        2 人    │
│   可申请编制数       3 人     │  │   可申请控制数        1 人    │
│                              │  │                              │
└──────────────────────────────┘  └──────────────────────────────┘
```

### 设计要点

- **左右并排**：两张卡片等宽，中间有明显间距，视觉上清晰对比
- **环形图上置**：每张卡顶部是环形图（donut chart），下方是字段列表
- **字段纵向排列**：每行 `标签 ……… 数值`，左对齐标签、右对齐数值，点状连接线
- **颜色区分**：事业编用蓝色系、控制数用绿色系（或共用一套绿/黄/红规则）
- **0 值处理**：控制数为 0 时（如幼儿园），环形图显示为灰色空环，标注"无控制数"

### 与扁平卡片的对比

| 维度 | 扁平 6 卡片 | 双卡分组 |
|------|:--:|:--:|
| 视觉层级 | 6 张卡片平铺，无主次 | 2 条线清晰，各自独立 |
| 对比效率 | 需左右扫视 6 个位置 | 左右并排 2 张卡即可对比 |
| 扩展性 | 加字段需加卡片 | 字段加在卡内即可 |
| 信息密度 | 每卡 1 个数字 | 每卡 1 图 + 7 个指标 |

### 受影响区域

此改动取代原来的"6 张汇总卡片 + 编制使用情况（进度条）"两个区域，合并为双卡区域。原 `renderSummaryCards()` 和 `renderQuotaUsage()` 合并为一个 `renderQuotaDashboard()`。

## 二、可申请数非负

### 2.1 问题

`careerAvailable = careerQuota - careerActual - careerApprovedPlan` 可能为负（已超额使用时）。

### 2.2 方案

显示时取 `Math.max(0, value)`，避免出现负数：

```javascript
// getComputed:
careerAvailable: Math.max(0, d.careerQuota - d.careerActual - d.careerApprovedPlan),
controlAvailable: Math.max(0, d.controlQuota - d.controlActual - d.controlApprovedPlan),
```

## 三、进度条 → 饼图

### 3.1 现状

```
事业编制
████████████████░░░░░  已用 80 / 核定 88   91%

控制数
██████████████░░░░░░  已用 14 / 核定 16   88%
```

### 3.2 方案

用内联 SVG 画圆环图（donut chart），视觉上更直观：

```
事业编制                    控制数
  ◯ 91%                      ◯ 88%
已用 80 / 核定 88          已用 14 / 核定 16
```

### 3.3 实现

使用 SVG circle + stroke-dasharray 绘制环形进度：

```html
<svg width="80" height="80" viewBox="0 0 36 36">
  <!-- 背景圆环 -->
  <circle cx="18" cy="18" r="15.5" fill="none" stroke="#E2E8F0" stroke-width="3"/>
  <!-- 前景圆环 -->
  <circle cx="18" cy="18" r="15.5" fill="none" stroke="currentColor"
    stroke-width="3" stroke-dasharray="91 9" stroke-dashoffset="25"
    stroke-linecap="round" transform="rotate(-90 18 18)"
    style="color: var(--success);"/>
  <!-- 中心文字 -->
  <text x="18" y="17" text-anchor="middle" font-size="7" fill="#1E293B" font-weight="700">91%</text>
  <text x="18" y="24" text-anchor="middle" font-size="4" fill="#94A3B8">已用 80</text>
</svg>
```

计算公式：
```javascript
var pct = comp.careerUsageRate; // 0-100
var circumference = 2 * Math.PI * 15.5; // ≈ 97.4
var dashLen = circumference * pct / 100;
var dashGap = circumference - dashLen;
```

### 3.4 颜色规则

| 使用率 | 颜色 | 含义 |
|:--:|------|------|
| < 70% | `var(--success)` 绿色 | 充裕 |
| 70%-90% | `var(--warning)` 黄色 | 偏紧 |
| > 90% | `var(--danger)` 红色 | 紧张 |
