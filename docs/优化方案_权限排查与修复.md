# 优化方案：权限排查与修复

> 日期：2026-06-15 | 状态：方案确认中，暂未实施

---

## 一、权限规则

| 角色 | 查看范围 | 审核范围 |
|------|----------|----------|
| 市管理员 | 全市所有学校 | 市直属学校 |
| 区管理员 | 本区属学校 | 本区属学校 |

---

## 二、排查发现：权限控制缺失

### 2.1 列表页（`org-ledger-admin.html`）

```javascript
// renderList() — 当前代码
filteredLedgers = schools.map(function(k) { return allLedgers[k]; });
// ... filter by filterStatus, filterDistrict, searchText ...
// ❌ 没有任何基于 currentUser.role 的过滤
```

**问题**：市管理员和区管理员看到的学校列表完全一样（取决于手动选择"区域"筛选项），区管理员可以查看市直属学校，不合规。

### 2.2 开关切换（`switchRole`）

```javascript
// 当前代码
currentUser = { role: role, name: cfg.name, id: 'D001', schoolName: '' };
// ❌ 切换到区管理员时，没有存储所属区域
```

**问题**：`currentUser` 缺少 `district` 字段，系统不知道区管理员属于哪个区。

### 2.3 详情/审核页（`org-ledger-detail.html`）

```javascript
// init() — 当前代码
ledger = allLedgers[schoolName];
// ... 直接渲染，没有任何权限检查
// ❌ 区管理员可以通过 URL 访问市直属学校的审核页
```

**问题**：区管理员可以直接修改 URL 参数进入市直属学校的审核页，越权操作。

### 2.4 审核按钮可见性

```javascript
// 列表页操作列 — 当前代码
if (status === 'pending') {
  h += '<a href="...&mode=review">审核</a>'; // ❌ 市直属的待审核也向区管理员展示
}
```

**问题**：区管理员在列表中可以看到市直属学校的"审核"按钮（虽然不该看到这些学校）。

## 三、修复方案

### 3.1 ROLES 配置增加 district 字段

```javascript
district: { name:'李振华', short:'区', district:'鱼峰区', sidebar:{...} }
```

区管理员默认归属鱼峰区（与 demo 数据一致）。

### 3.2 switchRole 存储 district

```javascript
currentUser = { 
  role: role, name: cfg.name, 
  id: role==='city'?'C001':role==='district'?'D001':role==='school'?'S001':'T001',
  district: cfg.district || '',
  schoolName: role==='school'?'柳州市第八中学':''
};
```

### 3.3 列表页按角色过滤

```javascript
// renderList() 中，在 filterDistrict 之前
var userDistrict = currentUser.district || '';
if (currentUser.role === 'district' && userDistrict) {
  // 区管理员只看本区学校
  filteredLedgers = filteredLedgers.filter(function(d) { 
    return d.district === userDistrict; 
  });
}
// 市管理员没有 district 字段，不过滤
```

### 3.4 详情页权限校验

```javascript
// org-ledger-detail.html init()
var userDistrict = currentUser.district || '';
if (currentUser.role === 'district' && userDistrict && ledger.district !== userDistrict) {
  document.getElementById('detailContent').innerHTML = 
    '<div class="form-card"><div style="text-align:center;padding:40px;color:var(--text-light);">'
    + '您无权查看该校的台账数据（所属区域：' + escapeHtml(ledger.district) + '）</div></div>';
  renderSidebar();
  return;
}
```

### 3.5 区管理员筛选栏调整

区管理员登录时，区域下拉框默认选中本区且不可切换为"全部区域"：

```javascript
// 区管理员：隐藏"全部区域"选项，只显示本区
if (currentUser.role === 'district') {
  h += '<span style="font-size:12px;color:var(--text-secondary);">区域：' + userDistrict + '</span>';
} else {
  // 市管理员：显示全部区域下拉
  h += '<select onchange="...">...</select>';
}
```

## 五、修复后效果

| 操作 | 市管理员 | 区管理员（鱼峰区） |
|------|:--:|:--:|
| 列表页 | 看到全部 14 所学校 | 只看到鱼峰区学校（八中/十三中/二十五中/实验小学/机关幼儿园/六中） |
| 区域筛选 | 可切换全部/市直属/鱼峰区/城中区/柳江区 | 固定显示"鱼峰区" |
| 审核按钮 | 市直属待审核可审核 | 只看鱼峰区待审核 |
| URL 越权 | — | 手动输入市直属学校 URL → 显示"无权查看" |
