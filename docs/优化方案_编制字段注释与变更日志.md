# 优化方案：编制字段注释

> 版本：v2.0 | 日期：2026-06-24 | 状态：方案确认中，暂不改代码

---

## 1. 背景

台账页面的编制信息卡片中，以下几个聚合字段需要增加注释，帮助用户理解每个字段的含义和计算逻辑：

| 字段 | 当前展示 | 缺少的信息 |
|------|---------|-----------|
| 已批复计划数 | 仅显示数字 | ① 仅统计**有效期内**的批复计划 ② 已到期计划不计入 ③ 从计划明细自动汇总 |
| 已使用计划数 | 仅显示数字 | ① = 有效期内计划记录的已入编人数之和 ② 从计划明细自动汇总 |
| 未使用计划数 | 仅显示数字 | ① = 已批复 − 已占用 − 已使用 − 暂缓 ② 四维度计算公式 |
| 可申请编制数 | 仅显示数字 | ① = 核定 − 实有 − 有效已批复 ② 已到期批复不参与计算 |

## 2. 优化方案

### 2.1 交互方式：ⓘ 角标 + 点击弹框

与补录弹窗中表头 ⓘ 的模式一致——每个聚合字段标签后跟一个 `ⓘ` 角标，点击弹出浮层展示注释内容和计算公式。

### 2.3 编辑模式 — 编制信息表单

编辑表单中聚合字段已 `readonly`，标签旁同样加 ⓘ 角标。点击弹出与查看模式相同的浮层。

### 2.4 浮层交互细节

| 属性 | 说明 |
|------|------|
| 触发方式 | 点击 ⓘ 角标 |
| 关闭方式 | ① 点击浮层内 `[ 知道了 ]` 按钮 ② 点击页面其他区域 |
| 定位 | 跟随点击位置，避开视口边缘 |
| 样式 | 白底 + 圆角 + 阴影，与补录弹窗的 ⓘ 浮层一致 |
| 复用 | 查看模式和编辑模式共用同一套浮层内容 |
