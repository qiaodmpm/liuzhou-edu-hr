# 岗位设置申请模块 — 产品需求文档

> 版本：v1.0 | 更新日期：2026-06-16 | 状态：已实施

---

## 1. 模块概述

### 1.1 业务背景

学校根据编制部门核定的编制数，按照规定的岗位结构比例，制定本单位的岗位设置方案。方案需经主管单位审核（一审）后，报送人社局审批。人社局批复后，学校录入核准结果，再由主管单位最终确认（二审），完成岗位设置。

### 1.2 核心概念

| 概念 | 说明 |
|------|------|
| 岗位总量 | = 总量控制数 — 小高地岗位数，不可超过 |
| 三类岗位 | 管理岗位、专业技术岗位、工勤技能岗位，占比有规定上限 |
| 等级分布 | 每类岗位下分若干等级，各等级人数之和 = 该类岗位合计 |
| 比例控制 | 不同类型学校有不同的岗位比例上限，系统自动校验 |

### 1.3 三类岗位结构

| 岗位类别 | 等级范围 | 说明 |
|---------|---------|------|
| 管理岗位 | 五级 ~ 十级（6个等级） | 学校行政管理人员 |
| 专业技术岗位 | 正高级(3-4级)、副高级(5-7级)、中级(8-10级)、初级(11-13级) | 教师主体 |
| 工勤技能岗位 | 一级 ~ 五级 + 普通工（6个等级） | 后勤保障人员 |

## 2. 角色与权限

### 2.1 参与角色

| 角色 | 身份 | 权限范围 |
|------|------|---------|
| 校管理员 | 学校人事干部 | 创建申请、录入人社结果、查看本校记录 |
| 区管理员 | 区教育局人事科 | 审核区属学校（一审 + 二审） |
| 市管理员 | 市教育局人事科 | 审核市直属学校（一审 + 二审），查看全部 |

### 2.2 审核归属规则

| 学校归属 | 审核人 |
|---------|--------|
| 市直属（柳州高级中学等） | 市管理员 |
| 鱼峰区属（柳州市第八中学等） | 区管理员（鱼峰区） |

## 3. 状态流转

### 3.1 状态枚举

| 状态值 | 中文标签 | 含义 |
|--------|---------|------|
| `first_review` | 待一审 | 学校已提交，等待主管单位材料审核 |
| `first_approved` | 一审通过 | 主管单位审核通过，等待学校录入人社结果 |
| `first_rejected` | 一审驳回 | 主管单位驳回，学校可修改重提 |
| `second_review` | 待二审 | 学校已录入人社结果，等待主管单位最终确认 |
| `completed` | 已完成 | 主管单位确认通过，流程结束 |

### 3.2 状态流转图

```
学校提交
    │
    ▼
┌──────────────┐     驳回      ┌───────────────┐
│  first_review │ ────────────→ │ first_rejected │
│    待一审      │               │    一审驳回     │
└──────┬───────┘               └───────┬───────┘
       │ 通过                          │ 编辑重提
       ▼                               │
┌──────────────┐                       │
│first_approved│                       │
│   一审通过    │                       │
└──────┬───────┘                       │
       │ 学校录入人社结果                │
       ▼                               │
┌──────────────┐                       │
│second_review │                       │
│   待二审      │                       │
└──────┬───────┘                       │
       │ 确认通过（不可驳回）             │
       ▼                               │
┌──────────────┐                       │
│  completed   │ ← 终态                 │
│   已完成      │                       │
└──────────────┘                       │
                                       │
       ┌───────────────────────────────┘
       ▼
  返回 first_review
```

### 3.3 各状态角色操作

| 状态 | 校管理员 | 区/市管理员 |
|------|---------|------------|
| `first_review` | 查看 | 审核（通过 / 驳回） |
| `first_approved` | **录入人社结果**、导出 | 查看 |
| `first_rejected` | **编辑重提** | 查看 |
| `second_review` | 查看 | **确认通过**（可修改数据） |
| `completed` | 查看、下载PDF | 查看 |

## 4. 四步进度

| 步骤 | 名称 | 操作角色 | 说明 |
|------|------|---------|------|
| Step 1 | 学校提交 | 校管理员 | 在线填写审核表并提交申报 |
| Step 2 | 一审：材料审核 | 区/市管理员 | 审核材料，填写意见，通过或驳回 |
| Step 3 | 学校提交人社结果 | 校管理员 | 线下报送人社局获批复后，录入核准结果并上传批复PDF |
| Step 4 | 二审：人社确认 | 区/市管理员 | 确认最终数据（可修改），不可驳回，确认后流程结束 |

| 正高级(3-4级) 合计 | 数字 | ✅ |
| 副高级(5-7级) 合计 | 数字 | ✅ |
| 中级(8-10级) 合计 | 数字 | ✅ |

| 字段 | 类型 | 必填 |
|------|------|:--:|
| 工勤技能岗位合计 | 数字 | ✅ |
| 一级 ~ 五级 + 普通工（各等级人数） | 数字 | ✅ |

#### 6.1.5 比例校验

| 校验项 | 规则 |
|--------|------|
| 管理岗位占比 ≤ 上限 | 按学校类型查表 |
| 专业技术岗位占比 ≥ 下限 | 同上 |
| 正高级 ≤ 上限 | 如初中 ≤ 1.5% |
| 副高级 ≤ 上限 | 如初中 ≤ 21.5% |
| 中级 ≤ 上限 | 如初中 ≤ 50% |
| 三类合计 = 岗位总量 | 必须相等 |
| 各等级之和 = 该类合计 | 必须相等 |

#### 6.1.6 附件上传

| 字段 | 类型 | 必填 | 约束 |
|------|------|:--:|------|
| 附件文件 | 文件上传 | ✅ | PDF/JPG/PNG/DOC/XLSX，≤10MB/个，最多10个，禁止压缩包 |

#### 6.1.7 人社结果录入（仅 `first_approved` 状态，mode=hr）

| 字段 | 说明 |
|------|------|
| 原始申报数（左列） | 只读，首次提交的值 |
| 人社核准数（右列） | 可编辑，按人社局批复文件填写 |
| 人社批复PDF | 必上传 |
| 差异汇总 | 自动计算原始 vs 核准的差异 |

## 附录 A — 申请编号规则

```
PS{YYYYMMDD}{序号}

PS     = 岗位设置模块前缀
日期   = 提交日期（8位）
序号   = 当日自增，从 001 开始

示例：PS20260522001 = 2026年5月22日第1份申请
```

| 学校类型 | 管理岗上限 | 专技岗下限 | 正高级上限 | 副高级上限 | 中级上限 |

| 初中 | 10% | 80% | 1.5% | 21.5% | 50% |
