# 优化方案：系统公告发布入口

## 背景

- 工作台页面（`workbench.html`）已有一个「系统公告」模块，展示来自市教育局、系统管理员等来源的公告列表（含未读蓝点、标题、日期、来源）
- 公告数据目前为各角色 demo 数据中硬编码的静态数组，无新增/编辑/删除能力
- 平台**没有任何页面或入口**可以发布、编辑、删除系统公告
- "查看全部 →" 链接仅弹出 toast 提示，无实际跳转
- PRD（系统基础模块）中未涵盖公告功能

## 现状分析

| 维度 | 现状 |
|------|------|
| 公告展示位置 | 工作台主内容区底部「系统公告」section |
| 数据存储 | `localStorage` 无持久化（Demo 模式硬编码在 JS 中） |
| 发布入口 | **无** |
| 可见角色 | 全部角色（市/区/校管理员、教师）均可见 |
| 公告字段 | 标题、日期、来源、已读/未读状态 |
| 交互 | 点击公告 → toast "打开公告详情"（无详情页）；点击"查看全部" → toast "查看全部公告"（无列表页） |

## 优化方案

### 方案概述

新增「公告管理」功能模块，归属系统基础模块，由**系统管理员、市管理员、区管理员、校管理员**负责发布和管理，全平台用户可在工作台查看公告。

**入口策略（方案 A：侧边栏 + 工作台双入口）——**

| 角色 | 入口方式 | 说明 |
|------|---------|------|
| 系统管理员 | 侧边栏「系统设置 → 公告管理」 | 无工作台，仅侧边栏入口 |
| 市/区/校管理员 | 侧边栏「系统设置 → 公告管理」+ 工作台「系统公告 → 查看全部 →」 | 两侧均可进入 |
| 教师 | 工作台「系统公告 → 查看全部 →」 | 无侧边栏菜单，仅工作台入口 |

> **设计决策**：教师角色的侧边栏菜单为空（历史设计），不新增教师侧边栏菜单。教师通过工作台公告模块进入公告列表页（只读视图）。

**核心规则：公告可见范围由发布者角色决定（向下包容）——**

| 发布者 | 可见范围 | 说明 |
|--------|---------|------|
| 系统管理员 | 全平台所有人 | 不限制单位归属 |
| 市管理员 | 全市所有人 | 本市下所有区、校的用户均可查看 |
| 区管理员 | 本区所有人 | 仅本区下所有校的用户可查看 |
| 校管理员 | 本校所有人 | 仅本校用户可查看 |

**查看者可见规则（向上包容）——**

| 查看者 | 可看到的公告 |
|--------|------------|
| 系统管理员 | 全部公告 |
| 市管理员 | 系统管理员发布 + 本市管理员发布 + 本市下各区/校发布的公告 |
| 区管理员 | 系统管理员发布 + 本市管理员发布 + 本区区管理员发布 + 本区下各校发布的公告 |
| 校管理员 | 系统管理员发布 + 本市管理员发布 + 本区区管理员发布 + 本校校管理员发布的公告 |
| 教师 | 与同校校管理员的可见范围一致（教师无发布权限）

### 一、新增页面

| 页面 | 文件 | 类型 | 访问角色 |
|------|------|------|----------|
| 公告管理列表 | `announcement-management.html` | 列表页 | 管理员（system/city/district/school）：侧边栏 + 工作台入口<br>教师：仅工作台入口（只读） |
| 公告详情 | `announcement-detail.html` | 详情页 | 全部已登录角色 |

> **说明**：`announcement-management.html` 对有发布权限的角色展示「发布公告」按钮 + 编辑/删除操作，对教师展示只读列表。各角色仅能看到其可见范围内的公告。

### 三、功能点清单

#### F06.01 发布公告（P0）

| 项目 | 内容 |
|------|------|
| 适用角色 | 系统管理员、市管理员、区管理员、校管理员 |
| 入口 | `announcement-management.html` 页面顶部「+ 发布公告」按钮 |
| 发布表单字段 | 标题（必填，限 100 字）、正文（必填，富文本或纯文本）、发布来源（自动填写当前管理员所属单位）、可见范围（自动根据发布者角色确定，不可更改：系统管理员→全平台、市管理员→全市、区管理员→本区、校管理员→本校）、生效时间（默认立即生效，可定时发布）、置顶（是/否） |
| 后置条件 | 公告写入 localStorage，可见范围内用户的工作台实时可见 |
| 交互规则 | 发布弹窗（modal），宽 640px；发布后列表刷新，新公告置顶 |

#### F06.02 编辑/删除公告（P1）

| 项目 | 内容 |
|------|------|
| 适用角色 | 系统管理员、市管理员、区管理员、校管理员 |
| 入口 | 公告管理列表中每行的「编辑」「删除」操作按钮（仅自己发布的公告可见操作按钮） |
| 业务规则 | 系统管理员可编辑/删除所有公告；市/区/校管理员仅可操作自己发布的公告 |
| 删除 | 二次确认弹窗 |

#### F06.03 公告列表管理（P0）

| 项目 | 内容 |
|------|------|
| 适用角色 | 管理员：查看可见范围内全部公告 + 操作自己发布的；教师：只读可见范围内公告 |
| 表头 | 标题、可见范围（全平台/全市/本区/本校）、发布来源、发布时间、状态（生效中/已过期/定时待发） |
| 筛选 | 支持按状态筛选（全部/生效中/已过期/定时待发）、按可见范围筛选 |
| 排序 | 置顶优先 → 发布时间倒序 |
| 分页 | 每页 10 条 |
| 可见规则 | 各角色仅看到其可见范围内的公告（详见方案概述中的查看者可见规则） |

#### F06.04 公告详情查看（P1）

| 项目 | 内容 |
|------|------|
| 适用角色 | 全部已登录角色 |
| 触发条件 | 点击工作台公告列表中的公告条目，或公告管理列表中的公告标题 |
| 页面内容 | 标题、发布来源、发布时间、正文（富文本） |
| 交互 | 返回按钮回到来源页面 |

#### F06.05 工作台公告模块升级（P1）

| 项目 | 内容 |
|------|------|
| 适用角色 | 全部已登录角色 |
| 变更点 | ① 数据源从硬编码 demo 数组改为读取 localStorage 公告存储<br>② 按当前用户所属单位过滤可见范围内的公告<br>③ 最多展示 5 条（置顶优先 → 时间倒序）<br>④ "查看全部 →" 跳转至 `announcement-management.html`（只读视图）<br>⑤ 新增「已过期」标签（灰色），生效中公告显示「新」蓝色标签 |

#### F06.06 公告到期自动下架（P2）

| 项目 | 内容 |
|------|------|
| 规则 | 公告可设截止时间，到期后自动标记为「已过期」，不再展示在工作台 |
| 默认 | 如未设截止时间，公告发布后 30 天自动过期 |

### 四、数据模型

```javascript
// localStorage key: 'announcements'
{
  id: 'ann_20260709_001',          // 公告 ID
  title: '关于2026年度公开招聘的通知', // 标题
  content: '<p>各区教育局、各学校：...</p>', // 正文（HTML）
  source: '市教育局',                 // 发布来源（自动取发布者所属单位名称）
  publisherId: '13807720000',       // 发布人 ID
  publisherName: '赵建国',           // 发布人姓名
  publisherRole: 'city',            // 发布人角色（system / city / district / school）
  scope: 'city',                    // 可见范围（system=全平台 / city=全市 / district=本区 / school=本校）
  scopeOrgId: '450200',             // 范围单位 ID（system 为空；city=市编码；district=区编码；school=学校 ID）
  publisherOrgId: '450200',         // 发布者所属单位 ID
  isPinned: false,                  // 是否置顶
  publishTime: '2026-07-09 10:00',  // 发布时间
  expireTime: '2026-08-08 10:00',   // 截止时间（默认 +30 天）
  status: 'active'                  // active | expired | scheduled
}
```

**可见范围判断逻辑（前端过滤）：**

```javascript
// 当前用户信息
var user = { role: 'school', orgId: '450202001', districtId: '450202', cityId: '450200' };

// 公告可见条件
function isVisible(announcement, user) {
  if (user.role === 'system') return true;                       // 系统管理员看全部
  if (announcement.scope === 'system') return true;              // 全平台公告所有人可见
  if (announcement.scope === 'city'
      && announcement.scopeOrgId === user.cityId) return true;   // 同市可见
  if (announcement.scope === 'district'
      && announcement.scopeOrgId === user.districtId) return true; // 同区可见
  if (announcement.scope === 'school'
      && announcement.scopeOrgId === user.orgId) return true;    // 同校可见
  return false;
}
```
