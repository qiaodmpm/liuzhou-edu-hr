# 优化方案：区管理员机构管理模块权限

> 日期：2026-06-17 | 状态：✅ 已实施

---

## 1. 现状

`org-management.html` 已支持区管理员访问（仅拦截 school/teacher），但权限受限：

| 功能 | 市管理员 | 区管理员 |
|------|:--:|:--:|
| 访问页面 | ✅ | ✅ |
| 左侧树形目录 | 柳州市 + 11 区县 | 仅本区（1 个节点） |
| 查看学校列表 | 全部 | 仅本区 ✅ |
| 查看台账 | ✅ | ✅ |
| 新建学校 | ✅ | ❌（按钮隐藏） |
| 编辑学校 | ✅ | ❌（按钮隐藏） |
| 停用/启用学校 | ✅ | ❌（按钮隐藏） |
| 副标题 | 柳州市 · 共 N 所机构 | "鱼峰区 · 教育机构信息（只读）" |

---

## 2. 优化目标

区管理员可对其所在区的学校进行完整的增删改查，但不能查看/操作其他区的学校。

| 功能 | 市管理员 | 区管理员（优化后） |
|------|:--:|:--:|
| 访问页面 | ✅ | ✅ |
| 查看所有区学校 | ✅ | ❌（仅本区） |
| 查看本区学校 | ✅ | ✅ |
| 新建学校 | ✅ | ✅（区域锁定为本区） |
| 编辑学校 | ✅ | ✅（仅本区学校） |
| 停用/启用 | ✅ | ✅（仅本区学校） |
| 删除学校 | ✅ | ✅（仅本区学校） |

---

## 3. 具体改动

仅涉及 1 个文件：`org-management.html`

### 3.1 侧边栏 — 区管理员增加"机构管理"菜单项

```javascript
// 改前（line 629-643）
district: { name:'李振华', short:'李', district:'鱼峰区', sidebar: [
  { id:'workbench', ... },
  ...
  { id:'account', label:'账号管理', icon:'user', group:'系统设置' }
]}

// 改后
district: { name:'李振华', short:'李', district:'鱼峰区', sidebar: [
  { id:'workbench', ... },
  ...
  { id:'account', label:'账号管理', icon:'user', group:'系统设置' },
  { id:'org', label:'机构管理', icon:'building', group:'系统设置' }   // ← 新增
]}
```

### 3.2 新建按钮 — 区管理员可见

```javascript
// 改前（line 513-517）
if (currentUser.role === 'district') {
  addBtn.style.display = 'none';
} else {
  addBtn.style.display = '';
}

// 改后
addBtn.style.display = '';  // 所有管理员均可新建
```

### 3.3 编辑/停用按钮 — 区管理员可见

```javascript
// 改前（line 909）
if (currentUser.role === 'city') {
  h += '<button ...>编辑</button>';
  // ... 停用/启用按钮
}

// 改后
if (currentUser.role === 'city' || currentUser.role === 'district') {
  h += '<button ...>编辑</button>';
  // ... 停用/启用按钮
}
```

### 3.4 副标题 — 去掉"（只读）"

```javascript
// 改前（line 535-537）
if (currentUser.role === 'district') {
  var d = currentUser.district || '';
  sub.textContent = d + ' · 教育机构信息（只读）';
}

// 改后
if (currentUser.role === 'district') {
  var d = currentUser.district || '';
  var cnt = orgDirectory.filter(function(o){return o.district===d && o.status==='active';}).length;
  sub.textContent = d + ' · 共 ' + cnt + ' 所机构';
}
```

### 3.5 表单 — 区管理员新建/编辑时锁定"所属区域"

在 `openAddModal` 和 `openEditModal` 中：

```javascript
// 区管理员：锁定所属区域为本区，不可修改
if (currentUser.role === 'district') {
  // 新建时：默认选中本区，下拉框禁用
  document.getElementById('fDistrict').value = currentUser.district;
  document.getElementById('fDistrict').disabled = true;
  
  // 编辑时：同样锁定
  // （已通过 getFilteredOrgs 保证只能编辑本区学校）
}
```

### 3.6 权限校验 — 双重保险

在保存/编辑/删除操作时增加区管理员越权校验：

```javascript
// 在 saveOrg / deleteOrg 中增加校验
if (currentUser.role === 'district') {
  var targetOrg = ...; // 被操作的学校
  if (targetOrg.district !== currentUser.district) {
    showToast('无权操作其他区的学校', 'warning');
    return;
  }
}
```

### 3.7 区管理员下拉框 — 仅显示本区管理员

在 `populateDistrictAdminSelect` 中，区管理员登录时只显示本区的区管理员账号：

```javascript
// 新增过滤逻辑
if (currentUser.role === 'district') {
  ADMIN_ACCOUNTS = ADMIN_ACCOUNTS.filter(function(a) {
    return a.district === currentUser.district;
  });
}
```

## 5. 安全边界

区管理员的数据隔离通过 **三层** 保障：

| 层级 | 机制 | 说明 |
|------|------|------|
| 数据层 | `getFilteredOrgs()` | 列表查询只返回本区数据（已有） |
| UI 层 | 下拉框禁用 + 按钮显隐 | 无法选择其他区域 |
| 逻辑层 | 保存时越权校验 | 即使绕过前端也无法跨区操作 |
