# 优化方案：学校台账页岗位结构排版

> 日期：2026-06-15 | 状态：方案确认中，暂未实施

---

## 一、现状问题

当前岗位结构卡包含以下内容，全部平铺在一个卡片里：

```
┌─ 📌 岗位结构 ──────────────────────────────────┐
│                                                    │
│  总量控制数：104  小高地岗位数：0  岗位总量：104       │
│                                                    │
│  岗位类别    │ 核定岗位数 │ 实有人数                  │
│  管理岗位    │     8     │    4                     │
│  专业技术岗位│    80     │   68                     │
│  工勤技能岗位│    16     │   22                     │
│  合计       │   104     │   94                     │
│                                                    │
│  管理岗位等级分布                                    │
│  五级1 六级2 七级2 八级2 九级1 十级0                  │
│                                                    │
│  专业技术岗位等级分布                                │
│  正高级：0人 ｜ 副高级：15人 ｜ 中级：45人 ｜ 初级：20人  │
│  正高级       副高级         中级           初级     │
│  三级0 四级0  五级3 六级6..  八级14 九级18.. 十一7..   │
│                                                    │
│  工勤技能岗位等级分布                                │
│  一级0 二级1 三级3 四级6 五级8  普通工：4             │
│                                                    │
└────────────────────────────────────────────────────┘
```

**问题**：
- 一张卡内容太长，滚动很久
- 等级分布（3 个区域）与汇总表并列，层级不清
- 专业技术岗位 4 级分类占据大量空间
- 不能快速定位到想看的等级分布

## 二、优化方案：折叠面板

### 2.1 布局

将岗位结构拆为「汇总表 + 3 个可折叠的等级分布面板」：

```
┌─ 📌 岗位结构 ──────────────────────────────────┐
│                                                    │
│  总量控制数：104  │  小高地：0  │  岗位总量：104       │
│                                                    │
│  ┌──────────────────────────────────────────┐     │
│  │ 岗位类别      │ 核定岗位数 │ 实有人数       │     │
│  │ 管理岗位      │     8     │    4          │     │
│  │ 专业技术岗位  │    80     │   68          │     │
│  │ 工勤技能岗位  │    16     │   22          │     │
│  │ 合计         │   104     │   94          │     │
│  └──────────────────────────────────────────┘     │
│                                                    │
│  ▶ 管理岗位等级分布  （五级1 六级2 七级2 ...）        │
│  ▶ 专业技术岗位等级分布  （副高15 中级45 初级20）     │
│  ▶ 工勤技能岗位等级分布  （二级1 三级3 四级6 ...）    │
│                                                    │
└────────────────────────────────────────────────────┘
```

### 2.2 折叠交互

- 默认全部折叠，仅显示汇总行（如 `管理岗位等级分布 8人 — 五级1 六级2 七级2 八级2 九级1 十级0`）
- 点击展开，显示等级网格
- 点击折叠，收起到汇总行

**折叠态**（一行摘要）：
```
▶ 专业技术岗位等级分布   80人 — 正高0 副高15 中级45 初级20
```

**展开态**：
```
▼ 专业技术岗位等级分布   80人 — 正高0 副高15 中级45 初级20
  ┌─────────────────────────────────────────────────┐
  │ 正高级  三级 0   四级 0                            │
  │ 副高级  五级 3   六级 6   七级 6                   │
  │ 中级    八级 14  九级 18  十级 13                  │
  │ 初级    十一级 8  十二级 8  十三级 4               │
  └─────────────────────────────────────────────────┘
```

### 2.3 实现

使用 `<details>` + `<summary>` 原生 HTML 折叠组件：

```html
<details open>
  <summary style="font-size:13px;font-weight:600;color:var(--primary);
    padding:8px 0;cursor:pointer;border-bottom:1px solid var(--border);">
    管理岗位等级分布
    <span style="font-weight:400;color:var(--text-secondary);font-size:12px;">
      — 五级1 六级2 七级2 八级2 九级1 十级0
    </span>
  </summary>
  <div style="padding:8px 0;">
    <!-- 等级网格 -->
  </div>
</details>
```

### 2.4 专业技术岗位 4 级合并展示

目前专业技术岗位的 4 个层级（正高/副高/中级/初级）各自一行，改为合并为一个网格：

```
专业技术岗位等级分布
┌──────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┬────┐
│      │三级│四级│五级│六级│七级│八级│九级│十级│十一│十二│十三│    │    │
├──────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┼────┤
│ 核定  │ 1  │ 4  │ 5  │ 10 │ 10 │ 15 │ 18 │ 15 │ 10 │ 10 │ 6  │ 0  │ 0  │
└──────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┴────┘
```

> 或者保持 4 行分组，在展开区域内紧凑排列。

## 三、等级数字显示优化

### 3.1 现状

`.level-grid` 用 5 列网格，每个格子 `背景+字`，但不同类别的等级数量不同（管理6个、专技4×不等、工勤5个），列数对齐不一致。

### 3.2 方案

统一用 `.level-grid` 但列数按等级数量动态设置：

| 类别 | 等级 | grid-template-columns |
|------|------|:--:|
| 管理岗位 | 5,6,7,8,9,10 | 6 列 |
| 专技-正高 | 3,4 | 2 列 |
| 专技-副高 | 5,6,7 | 3 列 |
| 专技-中级 | 8,9,10 | 3 列 |
| 专技-初级 | 11,12,13 | 3 列 |
| 工勤技能 | 1,2,3,4,5 + 普通工 | 6 列 |

## 四、改动清单

| # | 改动 | 说明 |
|---|------|------|
| 1 | 3 个等级分布区改为 `<details>` 折叠面板 | 默认折叠，仅显示摘要行 |
| 2 | 专业技术岗位等级分布合并展示 | 4 层级在一行网格中展示 |
| 3 | 等级网格列数动态适配 | 按实际等级数设置 `grid-template-columns` |
| 4 | 折叠摘要行显示等级概要 | 如 `五级1 六级2 七级2...` |
