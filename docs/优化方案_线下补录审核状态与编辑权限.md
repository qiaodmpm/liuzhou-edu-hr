# 优化方案：线下补录编辑权限

**版本**: v1.2  
**日期**: 2026-06-25  
**状态**: 已实施

---

## 一、规则

线下补录计划的编辑权限绑定台账编辑模式（`isEditing`），而非独立的审核状态。

| 条件 | 可编辑？ |
|------|----------|
| `isEditing = true`（台账处于编辑中） | ✅ |
| `isEditing = false`（台账已生效/只读） | ❌ |

> **原因**：审核是台账级别的，不存在对单条计划的独立审核。台账提交后由主管单位统一审批，驳回退回后学校进入编辑模式修改所有内容（包括线下补录计划）。
