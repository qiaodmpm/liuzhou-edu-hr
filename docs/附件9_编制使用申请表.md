# 附件9：中小学聘用教师控制数使用计划申报表

> 年度版本：（20XX年度）

## 表单字段

### 申请单位情况

| 字段 | 说明 |
|------|------|
| 单位全称 | 按规范第一名称填报 |
| 核定编制数（名） | 机构编制部门核定的编制总数 |
| 在编人数（人） | 当前在编实有人数 |
| 未使用计划数 | 已批复计划中尚未办理进编的人数 |
| 核定聘用教师控制数（名） | 机构编制部门核定的聘用教师控制数 |
| 聘用教师控制数实有数（人） | 当前聘用教师控制数实有人数 |
| 未使用控制数计划数 | 已批复计划中尚未办理增人手续的人数 |

## 说明

1. 单位全称栏按规范第一名称填报
2. 批准的控制数使用计划仅在有效期限内有效
3. 此表经市委编办批准同意后作为人社等部门办理有关手续的凭证
4. 申报时提交此表一式3份（正反双面打印）
