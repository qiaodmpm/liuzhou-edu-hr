# 业务规则：编制使用申请模块

## 2.1 编制使用申请模块

### 一、新进批次创建

- 采用简化方案，校/区管理员创建批次后，下级部门在截止日期前均可申报。
- 批次可设定适用范围（全市或特定区）。
- 批次发布后，允许编辑时间。
- 每个批次都可以申报两类编制类型，每类只允许机构申报 1 次/批次。

### 二、单位事业编制数和控制数信息

- **数据获取**：系统将自动从"柳州市人工智能助推教师队伍建设管理平台"获取单位的"核定事业编制数"、"在编人数"、"聘用控制数"等关键数据。
- **权限约束**：申报编制使用时，校管理员无权修改这类信息。

### 三、申报与审核

- 学校管理员可自主申报，也可在指定批次内申报。自主申报的默认选择自主申报批次。
- 批次内申报分为"事业编"和"控制数"两种类型，分别使用不同的表格（附件二 / 附件九）。
- 申请编制的审核通过后，学校管理员可导出"申请表"用于线下盖章。
- 申报审核驳回，允许重新编辑，重新提交审核。

### 四、审批结果录入

- **市委编办审批为线下流程**：学校将申请表（附件2/附件9）导出盖章后，线下报送市委编办审批。
- **结果回录**：市委编办线下审批完成后，由市/区管理员统一将审批结果录入平台（包括计划使用人数、使用期限），此结果作为后续编制数和控制数计数的依据。该录入适用于事业编和控制数两种类型。
- 录入最终的审批结果后，需要上传附件存档（选填），用于留存在线备案材料。
- 最终审批结果的计划使用人数会和学校的申报人数有出入（审批结果人数 ≤ 学校申报人数）。
- 若最终编办未审批通过，需要对审核结果进行驳回操作。
- **数据联动**：编办审批通过后，系统自动将审批通过的计划使用人数累加到对应学校的"未使用编制数"和"未使用控制数"中，作为后续编制管理和计数的依据。

### 五、附件上传通用规则

适用于编制使用申请、入编申请、出编申请等各类申请模块：

- 支持格式：Word（.doc/.docx）、Excel（.xls/.xlsx）、PDF、图片（.jpg/.jpeg/.png/.gif 等常见格式）。
- 单个文件大小上限：**10MB**。
- **不支持压缩包格式**（.zip / .rar / .7z / .tar 等）。
