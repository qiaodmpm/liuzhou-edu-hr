# 优化方案：机构编辑弹框排版优化

> 日期：2026-06-18 | 状态：✅ 已实施

---

## 1. 核心思路

按业务填写流程重新组织字段：**识别身份 → 归类编制 → 配置管理**。

编制属性内部遵循级联流：**组织类型 → 单位性质 → 单位类型 + 经费类型**。

---

## 2. 改前 vs 改后

### 2.1 改前（4 个 Fieldset，流程割裂）

```
┌─ 基本信息 ──────────────────────────┐
│  单位名称          单位简称          │
│  所属区域          组织类型   ← 触发源│
│  学校类型(cond)    学校分类标签      │
│  单位级别         (空洞)            │
└─────────────────────────────────────┘
┌─ 编制属性 ──────────────────────────┐
│  单位类型(cond)    单位性质          │
│  经费形式          信用代码          │
└─────────────────────────────────────┘
┌─ 管理员配置 ─┐ ┌─ 联系信息 ─┐
│  校管    区管 │ │  地址  电话 │
└──────────────┘ │  邮编      │
                 └────────────┘
```

**问题**：组织类型在基本信息里，但它直接驱动的字段都在编制属性里，视线来回跳。单位类型和经费形式上下排列，联动关系不直观。4 个框碎片化。

### 2.2 改后（3 个 Fieldset，按流程流动）

```
┌─ 基本信息 ──────────────────────────┐
│  单位名称          单位简称          │
│  所属区域          单位级别          │
└─────────────────────────────────────┘

┌─ 编制属性 ──────────────────────────┐
│                                      │
│  组织类型  ← 步骤 ①                  │
│  ┌──────────────────────────────┐   │
│  │  学校 / 行政管理部门 / 局属二层 │   │
│  └──────────────────────────────┘   │
│           ↓                         │
│  学校类型(cond)    学校分类标签(cond)│
│           ↓                         │
│  单位性质  ← 步骤 ②                  │
│  ┌──────────────────────────────┐   │
│  │  事业单位/参公/机关/其他       │   │
│  └──────────────────────────────┘   │
│           ↓                         │
│  单位类型  +  经费类型  ← 步骤 ③    │
│  ┌────────────┐ ┌──────────────┐   │
│  │公益一类     │ │全额拨款(联动) │   │
│  └────────────┘ └──────────────┘   │
│                                      │
│  统一社会信用代码                    │
│  ┌──────────────────────────────┐   │
│  └──────────────────────────────┘   │
└─────────────────────────────────────┘

┌─ 管理信息 ──────────────────────────┐
│  校管理员          区管理员          │
│  地址              电话              │
│  邮编                               │
└─────────────────────────────────────┘
```

## 4. 具体改动清单

### 4.1 字段重新分配

| 字段 | 改前位置 | 改后位置 | 说明 |
|------|----------|----------|------|
| 组织类型 | 基本信息 | **编制属性** | 它是编制流起点 |
| 学校类型 | 基本信息 | **编制属性** | 紧接组织类型 |
| 学校分类标签 | 基本信息 | **编制属性** | 紧接学校类型 |
| 单位级别 | 基本信息 | **基本信息** | 保持不变 |

### 4.2 标签重命名

| 字段 | 改前 | 改后 | 原因 |
|------|------|------|------|
| fFundType | 经费形式 | **经费类型** | 与"单位类型"形成配对关系 |
| fUnitType | 单位类型 | **单位类型** | 不变 |

### 4.3 合并 Fieldset

| 改前 | 改后 |
|------|------|
| 基本信息 | 基本信息（4 字段） |
| 编制属性 | 编制属性（组织类型 → 学校类型 → 单位性质 → 单位类型+经费类型 → 信用代码） |
| 管理员配置 | ↖ 合并进管理信息 |
| 联系信息 | 管理信息（管理员 + 地址 + 电话 + 邮编） |

### 4.4 条件字段处理

| 条件 | 学校类型 + 分类标签 | 单位类型 | 经费类型 |
|------|:---:|:---:|:---:|
| 组织类型 = 学校 | 显示 | 显示 | 联动可改 |
| 组织类型 = 行政管理部门 | 隐藏 | **隐藏** | **显示但锁定** |
| 组织类型 = 局属二层机构 | 隐藏 | 显示 | 联动可改 |

> 关键改进：行政管理部门时经费类型**不隐藏**，始终显示（锁定全额拨款），避免该行出现空洞。

### 4.5 CSS 新增

```css
.form-group.span-full { grid-column: 1 / -1; }
```

组织类型、单位性质、统一社会信用代码使用 `span-full` 跨两列，其余字段保持 1fr 1fr。

## 5. 改动汇总

| 文件 | 区域 | 改动 |
|------|------|------|
| org-management.html | CSS | + `.form-group.span-full` |
| org-management.html | HTML 基本信息 | 移除组织类型/学校类型/分类标签 |
| org-management.html | HTML 编制属性 | 重组字段顺序，组织类型置顶，标签"经费形式"→"经费类型" |

## 6. 视觉流对比

```
改前：基本信息 ─┬─ 组织类型（触发源在第一个框）
               ├─ 学校类型、分类标签
               └─ 单位级别
      编制属性 ─┬─ 单位类型
               ├─ 单位性质
               ├─ 经费形式
               └─ 信用代码
      ← 触发源和结果分离，需要视线跳跃

改后：基本信息 ─┬─ 单位名称、简称
               └─ 所属区域、单位级别
      编制属性 ─┬─ ① 组织类型
               ├─    → 学校类型 + 分类标签
               ├─ ② 单位性质
               ├─ ③ 单位类型 + 经费类型
               └─    信用代码
      ← ①→②→③ 自上而下，一步一响应
```
