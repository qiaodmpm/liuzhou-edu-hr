<!-- ===== 入编方式联动方案 ===== -->
<h2>六、合同制教师"入编方式"处理方案</h2>

<div class="anno">
  <strong>方案：编制类型联动隐藏入编方式</strong><br><br>
  当编制类型选择"合同制"时：
  <ul style="margin-left:16px;">
    <li>入编方式下拉框 + 标签 <strong>整行隐藏</strong>（不是 disable，是直接 display:none）</li>
    <li>保存时入编方式 <strong>自动写入空字符串 ""</strong></li>
  </ul>
  当编制类型从合同制切换回事业编/控制数时：
  <ul style="margin-left:16px;">
    <li>入编方式<strong>重新显示</strong>，值恢复为之前保存的值（或留空待填）</li>
  </ul>
  理由：合同制教师签劳动合同，走的是"编外教师管理"模块，不存在"入编方式"这个概念。隐藏比 disable 更好，避免用户困惑"为什么这个字段不能点"。
</div>
