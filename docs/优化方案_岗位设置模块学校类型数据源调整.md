# 优化方案：岗位设置模块"学校类型" → "岗位设置分类"

> 日期：2026-06-18 | 状态：✅ 已实施

---

## 1. 现状

岗位设置申请模块（`post-*.html`）有"学校类型"字段，当前存在两个问题：

| # | 问题 | 详情 |
|---|------|------|
| 1 | **标签不准确** | 字段名为"学校类型"，但实际用途是确定岗位设置比例，机构管理已将对应字段命名为"岗位设置分类" |
| 2 | **数据源割裂** | 各文件硬编码 `schoolType` 映射，与 `org_directory.schoolCategory` 不一致 |

### 1.1 当前分布（6 个源文件，11 处）

| 文件 | 出现次数 | 上下文 |
|------|:--:|------|
| `post-form.html` | 2 | 表单展示 + 校验 |
| `post-list-admin.html` | 4 | 列表表头 + 筛选 + 导出表头 ×2 |
| `post-list-school.html` | 2 | 列表表头 + 导出 |
| `post-audit-first.html` | 1 | 一审详情 |
| `post-audit-second.html` | 1 | 二审详情 |
| `post-detail.html` | 1 | 详情页 |

---

## 2. 优化目标

| 维度 | 改前 | 改后 |
|------|------|------|
| 字段标签 | 学校类型 | **岗位设置分类** |
| 数据来源 | 各文件硬编码 `schoolType` | 统一从 `org_directory.schoolCategory` 读取 |
| 与机构管理一致性 | ❌ 独立维护 | ✅ 同源同标签 |

### 3.2 数据源统一（每个文件新增 1 个函数 + 替换取值逻辑）

每个 `post-*.html` 新增从 `org_directory` 读取映射的公共函数：

```javascript
function getSchoolCategoryMap() {
  var map = {};
  var stored = localStorage.getItem('org_directory');
  if (stored) {
    try {
      JSON.parse(stored).forEach(function(o) {
        if (o.orgName) map[o.orgName] = o.schoolCategory || o.schoolType || '';
      });
    } catch(e) {}
  }
  return map;
}
```

然后替换各处 `schoolType` 的取值逻辑：

| 文件 | 改动 |
|------|------|
| `post-form.html` | SCHOOL_DATA 中 `schoolType` → 从 map 取值；mockRecords 中 `schoolType` → 从 map 取值 |
| `post-list-admin.html` | 渲染 `r.schoolType` → `getSchoolCategoryMap()[r.schoolName]` |
| `post-list-school.html` | 同上 |
| `post-audit-first.html` | `r.schoolType` → 从 map 取值 |
| `post-audit-second.html` | `r.schoolType` → 从 map 取值 |
| `post-detail.html` | `record.schoolType` → 从 map 取值 |

### 3.3 示例：post-form.html 改动前后对比

```diff
// SCHOOL_DATA 改前
'柳州高级中学': { schoolType: '自治区示范高中', orgLevel: '正处级', ... },

// SCHOOL_DATA 改后
'柳州高级中学': { orgLevel: '正处级', ... },

// 渲染时
- formData.schoolType = SCHOOL_DATA[formData.schoolName].schoolType;
+ formData.schoolType = getSchoolCategoryMap()[formData.schoolName] || '';
```
