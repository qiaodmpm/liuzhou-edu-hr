# 产品方案：编外教师管理模块

**版本**: v2.0  
**日期**: 2026-06-25  
**状态**: 待确认

---

## 一、需求概述

左侧菜单栏"聘用管理"下方新增菜单组"编外教师管理"，包含：

| 菜单项 | 说明 |
|--------|------|
| 教师入职管理 | 合同制教师入职申报 + 主管单位审核 |
| 教师离职管理 | 合同制教师离职申报 + 主管单位审核 |

核心业务模型：

```
学校管理员：    创建申报（一条 = 一个批次，含 1~N 名教师）
                      ↓
主管单位：      以批次为单位审核（整批通过 / 整批驳回）
```

**关键约束**：
- 每次申报是一条数据，一个批次可包含多位教师
- 审核以批次为单位，批次内所有教师一起通过或一起驳回，不单独审核
- 入职必传：劳动合同 + 每位教师的身份证正反面
- 离职必传：解除劳动合同证明

---

## 二、菜单结构

```
聘用管理
  └─ 聘用手续办理

编外教师管理                        ← 新增
  ├─ 教师入职管理
  └─ 教师离职管理
```

city / district / school 角色显示，teacher 不显示。

## 五、审核流程

```
                    学校管理员
                        │
                        │ 创建申报（批次）
                        │ 含 1~N 名教师 + 附件
                        │ 提交 → 状态 = pending
                        ↓
                    主管单位
                        │
                        │ 查看批次详情
                        │ 审核 → 整批通过 or 整批驳回
                        │
                   ┌────┴────┐
                   ↓         ↓
              approved   rejected
              （全部教师   （全部教师
               一起通过）   一起驳回）
```

| 规则 | 说明 |
|------|------|
| 审核粒度 | 以**批次**为单位，不可拆分审核批次内个别教师 |
| 通过 | 批次状态 → `approved`，整批教师入职/离职生效 |
| 驳回 | 批次状态 → `rejected`，需填写驳回意见，学校可查看并重新申报 |
| 批量操作 | 主管列表页支持勾选多条批次 → 一键批量通过/驳回 |

## 八、侧边栏改动

约 42 个源文件的 `ROLES`（city/district/school 角色）中 `聘用管理` 组下方插入：

```js
{ name: '编外教师管理', items: [
  { id: 'contract-entry', label: '教师入职管理' },
  { id: 'contract-exit', label: '教师离职管理' }
]}
```

`sidebarClick()` 中新增路由：

```js
if (id === 'contract-entry') {
  window.location.href = (currentUser.role === 'city' || currentUser.role === 'district')
    ? 'contract-entry-list-admin.html' : 'contract-entry-list-school.html';
  return;
}
if (id === 'contract-exit') {
  window.location.href = (currentUser.role === 'city' || currentUser.role === 'district')
    ? 'contract-exit-list-admin.html' : 'contract-exit-list-school.html';
  return;
}
```
