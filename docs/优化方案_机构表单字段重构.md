### 2.4 新增字段：单位类型（公益分类）

在原"单位类型"字段改名为"组织类型"后，新增一个独立的"单位类型"字段（数据字段名 `unitType`）。

#### 字段属性

- **位置**：组织类型字段之后，编制属性 fieldset 内
- **标签**：单位类型
- **显隐规则**：仅当 `组织类型 ≠ 行政管理部门` 时显示

#### 枚举值

| 值 | 含义 | 联动：经费形式 |
|----|------|:-------------:|
| 公益一类 | 公益一类事业单位 | 全额拨款 |
| 公益二类 | 公益二类事业单位 | 差额拨款 |
| 行政部门 | 行政类 | 全额拨款 |

#### 联动逻辑

```
onOrgTypeChange() 基础上扩展：

if (组织类型 === '行政管理部门') {
    隐藏"学校类型"
    隐藏"单位类型"（新字段）
    经费形式 自动设为"全额拨款" 且 disabled
} else if (组织类型 === '学校') {
    显示"学校类型"
    显示"单位类型"（新字段）
    经费形式 根据"单位类型"自动联动：
        公益一类 → 全额拨款
        公益二类 → 差额拨款
        行政部门 → 全额拨款
} else if (组织类型 === '局属二层机构') {
    隐藏"学校类型"
    显示"单位类型"（新字段）
    经费形式 联动规则同上
}
```

#### HTML 片段

```html
<div class="form-group" id="fgUnitType">
  <label>单位类型 <span class="required">*</span></label>
  <select id="fUnitType" onchange="onUnitTypeChange()">
    <option value="公益一类">公益一类</option>
    <option value="公益二类">公益二类</option>
    <option value="行政部门">行政部门</option>
  </select>
</div>
```

#### JS 联动函数

```javascript
function onUnitTypeChange() {
  var ut = document.getElementById('fUnitType').value;
  var ft = document.getElementById('fFundType');
  switch (ut) {
    case '公益一类': ft.value = '全额拨款'; break;
    case '公益二类': ft.value = '差额拨款'; break;
    case '行政部门': ft.value = '全额拨款'; break;
  }
}
```

#### 经费形式 disabled 逻辑

| 组织类型 | 单位类型 | 经费形式 |
|----------|----------|:-------:|
| 行政管理部门 | —（隐藏） | 自动 = 全额拨款，disabled |
| 学校 | 公益一类/二类/行政部门 | 可手动改 |
| 局属二层机构 | 公益一类/二类/行政部门 | 可手动改 |

> 仅行政管理部门时锁定经费形式；学校和局属二层机构经费形式可手动覆盖（防止少数情况不符）。

## 3. 数据模型变更

### 3.1 新增字段 `unitType`

每条 org 记录新增一个字段：

```javascript
unitType: '公益一类' | '公益二类' | '行政部门' | ''
// '' 用于行政管理部门（不适用）
```

### 3.2 ID 生成逻辑不变

`gxlzh-{regionCode}-{seq}` 格式不变，按 district 分组自增。

### 3.3 列表展示

列表页"学校类型"列需调整——当组织类型为教育局或局属二层机构时显示组织类型名：

当前已有 fallback：`o.schoolType || o.orgType`，但组织类型改名后，`o.orgType` 会显示"行政管理部门"或"局属二层机构"，符合预期。

## 4. onOrgTypeChange() 完整逻辑

```javascript
function onOrgTypeChange() {
  var t = document.getElementById('fOrgType').value;
  
  // 学校类型：仅学校显示
  document.getElementById('fgSchoolType').style.display = (t === '学校') ? '' : 'none';
  
  // 单位类型（新字段）：行政管理部门时隐藏
  document.getElementById('fgUnitType').style.display = (t === '行政管理部门') ? 'none' : '';
  
  // 单位性质默认值
  var natureEl = document.getElementById('fOrgNature');
  if (t === '行政管理部门') {
    if (!natureEl.dataset.userSet) natureEl.value = '机关单位';
  } else if (t === '局属二层机构') {
    if (!natureEl.dataset.userSet) natureEl.value = '事业单位';
  } else {
    if (!natureEl.dataset.userSet) natureEl.value = '事业单位';
  }
  
  // 经费形式：行政管理部门锁定全额拨款
  var fundEl = document.getElementById('fFundType');
  if (t === '行政管理部门') {
    fundEl.value = '全额拨款';
    fundEl.disabled = true;
  } else {
    fundEl.disabled = false;
    onUnitTypeChange();  // 根据单位类型自动联动
  }
}
```
