# 业务规则：入编与出编管理模块

## 2.2 入编与出编管理模块

### 一、入编申请

- **操作主体**：由校管理员代表学校进行，而非教师个人操作。
- **申请方式**：学校自主申报，无需创建批次。
- **前置条件**：教师需先在"柳州市人工智能助推教师队伍建设管理平台"注册账号，入编申请通过后，再在本平台完善个人信息并登录。
- **申报模式**：
  - **备案制（控制数人员）**：可以一次批量申报多人。
  - **实名制（事业编人员）**：一次只能申报一人。
- **审核流程**：申请被审批通过后，无需二次录入审批结果。
- **修改期**：管理员可对已通过的入编申请进行"驳回"，并保留 **30 天**的修改期。

### 二、出编申请

- **操作主体**：由校管理员发起。
- **适用范围**：处理退休、辞职、解聘等人员的出编事宜。
- **申请方式**：校管理员自主申报，**无需创建批次**，平铺申请列表。
- **申报模式（双轨制）**：
  - **事业编**：多人表格（支持动态增删行），出编形式 8 种（调动/退休/辞职/辞退/解除聘用合同/开除/在职人员亡故/离退休人员亡故核减），逐人上传证明材料。
  - **控制数**：多人表格（支持动态增删行），减员形式 4 种（辞职/退休/解除控制数聘用关系/亡故），逐人上传证明材料。
  - 两种类型均**不支持 Excel 导入**，仅支持手动逐条添加。
  - 编制类型**单选**，提交后不可修改。
- **单位信息**（自动带出）：
  - 事业编：单位名称 + 编制类型（行政编制/事业编制/机关工勤"老办法"人员，三选一，系统预置，学校管理员可修改）。
  - 控制数：单位名称 + 控制数类型（四选一，预置可修改）+ 核定控制数/现有控制数人员（自动带出）+ 本次备案控制数人员/备案后控制数人员（自动计算）。
- **出编/减员形式与材料**：每种形式对应不同的必传证明材料，依据文号为条件必填（亡故可不填）。
- **审批流程**：
  - **单步审批**：区属学校 → 区教育局审批；市直属学校 → 市教育局审批。
  - **整体通过/驳回**：控制数批次整体审批，不支持部分通过。
  - 审批通过后结果**不可修改**（无 30 天窗口），立即生效。
- **审批通过后自动操作**：
  1. 更新在编人员库/控制数人员库（删除或标记为"已出编"）
  2. 更新单位编制统计：
     - 事业编：在编人数减少；**未使用编制数增加**（核定编制数不变）
     - 控制数：现有控制数人员减少；**未使用控制数增加**（核定控制数不变）
  3. 生成出编台账记录
- **驳回与重提**：被驳回的申请，校管理员可修改人员信息、材料后**整体重新提交**，状态恢复为"待审核"。
- **市管理员权限**：可查看全市出编记录（只读），仅对市直属学校待审核申请可审批，**仅导出已通过申请**。
- **提交规则**：提交后不可取消，无草稿状态；中途退出填写内容不保存。

## 2.3 数据与附件管理

### 一、数据源

- 平台的核心数据（如教师信息、单位信息）将从"柳州市人工智能助推教师队伍建设管理平台"同步获取。

### 二、附件上传通用规则

适用于编制使用申请、入编申请、出编申请等各类申请模块：

- 支持格式：Word（.doc/.docx）、Excel（.xls/.xlsx）、PDF、图片（.jpg/.jpeg/.png/.gif 等常见格式）。
- 单个文件大小上限：**10MB**。
- **不支持压缩包格式**（.zip / .rar / .7z / .tar 等）。
