# PRD：岗位晋升申请模块

> 版本: v1.0 | 日期: 2026-05-25 | 状态: 待开发

---

## 一、项目背景与目标

### 1.1 业务背景

根据《柳州市事业单位岗位设置管理实施细则》，专业技术岗位内部等级晋升需经过"单位推荐、主管部门审核、人社确认"三级程序。为规范线上操作，实现教师申报、学校审核、主管部门材料审核、人社确认的全流程数字化管理，需建设岗位晋升模块。

### 1.2 产品目标

- 支持市/区教育局发布岗位晋升批次
- 教师在线申报，根据晋升类型填写相应表单
- 学校管理员（一审）对教师申报进行审核（可修改资料、补充附件），并批量提交至主管部门
- 主管部门管理员（二审）对材料进行审核（通过需二次确认，驳回需填写原因）
- 学校管理员根据人社批复录入最终结果，提交三审
- 主管部门管理员（三审）进行最终确认（不可驳回，可修改资料）
- 实时展示"剩余可申报岗位数"，控制超岗

## 四、核心业务流程

```
主管部门发布批次 → 教师在线申报 → 学校一审（单位审核 + 批量提交）
    → 主管部门二审（材料审核）→ 学校录入人社结果
    → 主管部门三审（最终确认）→ 晋升成功
```

### 流程说明

| 阶段 | 执行角色 | 线上/线下 | 操作描述 |
|------|---------|----------|---------|
| 0. 批次发布 | 市/区管理员 | 线上 | 创建晋升批次，设定适用范围、可申报等级、起止时间 |
| 1. 教师申报 | 教师 | 线上 | 选择批次，填写申报表（根据晋升类型自动切换表单），上传附件 |
| 2. 一审（单位审核） | 学校管理员 | 线上 | 逐人审核教师申报（可修改资料、补充附件、通过/驳回），审核完成后批量勾选通过的申请，确认汇总表后统一提交至主管部门 |
| 3. 二审（材料审核） | 市/区管理员 | 线上 | 逐人审核材料，通过需二次确认，驳回需填写原因 |
| 4. 线下流转 | 学校/主管单位/人社 | 线下 | 主管单位汇总报人社 → 人社批复 |
| 5. 录入人社结果 | 学校管理员 | 线上 | 录入核准结果，上传人社批复PDF，提交三审 |
| 6. 三审（最终确认） | 市/区管理员 | 线上 | 可修改资料（记录日志），确认通过（不可驳回），系统自动更新岗位等级 |

### 状态流转

```
教师提交 → 一审待审核
    ├→ 一审驳回 → 教师修改重提 → 一审待审核
    └→ 一审通过（待学校提交）→ 学校批量提交（同一审流程内）→ 二审待审核
        ├→ 二审驳回 → 学校修改/驳回教师 → 重新提交 → 二审待审核
        └→ 二审通过 → 学校录入人社结果 → 三审待审核
            └→ 三审确认通过 → 晋升成功
```

## 五、功能详细说明

### 5.1 批次管理（主管部门）

市/区教育局管理员可创建岗位晋升批次：

| 字段名称 | 字段类型 | 必填 | 说明 |
|---------|---------|:---:|------|
| 批次名称 | 文本 | 是 | 如"2026年春季专业技术岗位晋升" |
| 适用岗位类别 | 下拉（默认专业技术岗位） | 是 | 暂只支持专业技术岗位 |
| 可申报的晋升等级范围 | 多选 | 是 | 如"允许四级→三级、七级→六级" |
| 申报开始时间 | 日期时间 | 是 | — |
| 申报结束时间 | 日期时间 | 是 | — |
| 适用范围 | 多选下拉 | 是 | "全市"或指定区（城中区、鱼峰区、柳南区等，可多选） |
| 备注 | 文本 | 否 | — |

**规则**：
- 批次发布后，教师在首页/岗位晋升页面可见可申报的批次
- 若批次未设置，则全年开放（默认批次）
- 适用范围选"全市"时，所有学校教师均可见
- 适用范围选指定区时，仅被选中区所属学校的教师可见
- 指定区的批次，仅相关区教育局管理员有审核权限；市教育局管理员可查看所有批次数据

### 5.2 教师端申报

#### 5.2.1 入口与批次选择

- 教师登录 → 岗位晋升 → 新建申报

#### 5.2.2 表单类型判断

- **常规晋升**（非四级→三级）：展示通用基本信息表（见5.2.3）
- **四级→三级**：展示四级升三级专项表（见5.2.4），不显示通用表

#### 5.2.5 剩余可申报岗位数提示

- **计算公式**：核定岗位数 − 实聘数 − 已提交待审批人数
- 若剩余 ≤ 0，禁用提交按钮并提示"无可申报岗位数"

#### 5.2.6 附件上传

- 教师必须上传至少 1 个附件（资格证、聘书、公示材料等）
- 格式：PDF / Word / 图片
- 单文件 ≤ 20MB

#### 5.2.7 提交

- 提交后申请状态变为"一审待审核"（待学校审核）

### 5.3 一审：学校审核（含批量提交）

一审是学校管理员的完整操作流程，包含逐人审核和批量提交两个环节。

#### 5.3.1 待审核列表

- 学校管理员查看本校所有"一审待审核"申请，支持筛选

#### 5.3.2 逐人审核

- 可查看/修改教师填写的申报表（所有字段可编辑）
- 可补充上传附件（不可删除教师原有附件）
- 可查看岗位聘用汇总表、剩余可申报岗位数（实时）
- **通过**：申请状态变为"一审通过，待学校提交"
- **驳回**：必须填写驳回原因，退回教师修改

#### 5.3.3 批量提交至主管部门

- 学校管理员可勾选多条"一审通过，待学校提交"的申请，点击"批量提交"
- 二次确认后，状态统一变为"二审待审核"（材料审核）
- 点击批量提交时，需要确认岗位聘用汇总表
- 被驳回的申请（二审驳回退回学校的），学校管理员可以选择：
  - 修改资料（只针对被驳回的人员，已通过的人员不需要重新修改）
  - 驳回给教师重新修改提交

### 5.4 二审：材料审核（主管部门）

#### 5.4.1 待审核列表

- 主管部门管理员查看本辖区所有"二审待审核"申请

#### 5.4.2 审核操作

- **通过**：弹出二次确认框，可填写审核意见（选填）；状态变为"二审通过"，通知学校录入人社结果
- **驳回**：必须填写驳回原因，状态变为"二审驳回"，退回学校管理员（学校可重新修改或驳回给教师）
- 审核时，可对申报的学校的每个人进行通过/驳回操作
- 每个学校若有一个人审核不通过，则该校的申报要驳回到学校，重新修正提交

### 5.5 学校录入人社结果

- 二审通过后，学校管理员在申请详情页点击"录入人社结果"
- 录入内容：核准等级、依据文号、备注
- 上传人社批复PDF（**必传**）
- 保存后状态变为"三审待审核"

### 5.6 三审：人社确认（主管部门）

#### 5.6.1 待审核列表

- 主管部门管理员查看所有"三审待审核"申请

#### 5.6.2 确认操作

- **可修改资料**：对教师申报信息、人社核准结果进行修正（记录修改日志）
- **确认通过**：点击后流程结束，状态变为"晋升成功"，系统自动更新教师岗位等级及单位岗位聘用汇总表中的实聘数
- **不提供驳回按钮**

## 六、超岗控制规则

| 校验时机 | 说明 |
|---------|------|
| 教师提交时 | 剩余可申报岗位数 ≤ 0 时阻止提交 |
| 一审通过时 | 校验剩余岗位数，≤ 0 时阻止 |
| 二审通过时 | 校验剩余岗位数，≤ 0 时阻止 |

**例外**：专技 8-13 级允许超岗，不做控制。

**剩余可申报岗位数计算公式**：
```
剩余可申报岗位数 = 核定岗位数 − 实聘数 − 已提交待审批人数
```

## 七、批次可见性与审核权限

| 适用范围配置 | 教师可见性 | 审核权限 |
|------------|-----------|---------|
| 全市 | 所有学校教师均可见 | 区管理员审核本区、市管理员审核市直属 |
| 指定区（如鱼峰区） | 仅被选中区所属学校的教师可见 | 仅相关区教育局管理员有审核权限 |
| 指定区（多区） | 被选中的多个区所属学校教师可见 | 各区管理员审核本区学校 |

市教育局管理员可查看所有批次数据（只读），但仅对市直属学校有审核权限。

## 九、验收标准

| 编号 | 验收项 | 通过标准 |
|:---:|--------|---------|

| PR-16 | 批次教师可见性（指定区） | 选择指定区时，仅被选中区所属学校的教师可见 |
| PR-17 | 审核权限隔离 | 指定区的批次，仅相关区管理员有审核权限；市管理员可查看所有批次数据 |
