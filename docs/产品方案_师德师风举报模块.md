# 师德师风举报模块 — 产品方案

## 1. 业务流程

```
                        ┌─ 市直属 ──▶ 市管理员直接处理 ──▶ 自动归档 ✅
                        │
市管理员录入举报 ──▶ 系统自动匹配区划
（手动录入+Excel导入并存）│
                        └─ 区属 ──▶ 指派区管理员 + 设置截止日期
                                          │
                                          ▼
                                    区管理员查处处理
                                          │
                                          ▼
                                    市管理员审批
                                          │
                                    ┌─────┴─────┐
                                    ▼            ▼
                                  通过          驳回
                               ✅ 已完成      区重新处理（可重新设期限）
```

## 2. 状态流转

| 状态码 | 含义 | 适用 | 谁操作 |
|--------|------|------|--------|
| `pending_assign` | 已录入，待指派 | 区属 | — |
| `pending_process` | 已指派，待处理 | 区属 / 市直属 | 区管理员或市管理员 |
| `pending_review` | 已提交处理结果，待审批 | 区属 | 市管理员 |
| `completed` | 已完成 | 全部 | — |
| `rejected` | 审批驳回 | 区属 | 区管理员 |

**市直属简化流**: 录入 → 系统标记为"市直属，免指派" → 市管理员直接进入处理页 → 提交后自动 `completed`，无需审批。

## 3. 字段规范

### 3.1 举报信息区（市管理员录入）

| 字段 | 字段代码 | 类型 | 必填 | 说明 |
|------|---------|------|------|------|
| 线索来源 | `source` | select | 是 | 邮箱投诉 / 电话举报 / 信件举报 / 网络举报 / 其他 |
| 被举报人姓名 | `reportedName` | text | 是 | |
| 被举报单位 | `reportedUnit` | text | 是 | |
| 反映的主要问题 | `complaintContent` | textarea | 是 | |

### 3.2 被举报人基本信息区（市录入，区可补充）

| 字段 | 字段代码 | 类型 | 必填 | 对齐来源 |
|------|---------|------|------|---------|
| 单位名称 | `unitName` | text | 是 | 出编/台账 `单位名称` |
| 姓名 | `name` | text | 是 | 全模块 `姓名` |
| 身份证件类型 | `idCardType` | select | 是 | 居民身份证/护照/其他（本模块新增） |
| 身份证号 | `idCard` | text(18) | 是 | 入编/出编 `身份证号` |
| 性别 | `gender` | select | 是 | 全模块 `性别`（男/女） |
| 年龄 | `age` | number | 是 | 退休模块 `年龄` |
| 人员类别 | `personType` | select | 是 | 专任教师/行政人员/教辅人员/工勤人员/其他 |

### 3.3 处理结果区（区/市管理员填写）

| 字段 | 字段代码 | 类型 | 必填 |
|------|---------|------|------|
| 查明的基本情况 | `investigation` | textarea | 是 |
| 处理依据 | `basis` | textarea | 是 |
| 对本人的处理 | `penalty` | textarea | 是 |
| 对相关责任人的追责情况 | `accountability` | textarea | 是 |
| 是否通报 | `isNotified` | select | 是（是/否） |
| 以何种形式、在何范围通报 | `notificationScope` | textarea | 条件必填（是否通报=是时） |
| 创建单位 | `processingUnit` | text | 只读，自动带出处理单位 |

### 3.4 附件区（选填）

| 阶段 | 字段代码 | 说明 |
|------|---------|------|
| 录入阶段 | `attachments_import` | 举报原始材料（邮件截图、举报信等），选填 |
| 处理阶段 | `attachments_process` | 处理结果附件（处分文件等），选填 |

## 4. 页面清单

| 页面 | 文件 | 角色 | 说明 |
|------|------|------|------|
| 市管理员列表页 | `ethics-list-city.html` | 市 | 全量，筛选：状态/区划/学校/日期/市直属开关 |
| 区管理员列表页 | `ethics-list-district.html` | 区 | 本区，筛选：状态/学校/日期 |
| 学校管理员列表页 | `ethics-list-school.html` | 校 | 本校，只读 |
| 录入弹窗 | 含于列表页 | 市 | 手动录入表单 |
| Excel导入弹窗 | 含于列表页 | 市 | 上传+解析预览 |
| 处理页 | `ethics-process.html` | 市/区 | 填写处理结果+附件 |
| 审批页 | `ethics-review.html` | 市 | 审批通过/驳回（驳回需填意见+重设期限） |
| 详情页 | `ethics-detail.html` | 市/区/校 | 只读，布局对齐编制使用申请详情页 |

### 编号规则

- 批次：`ET{YYYY}{region}-{seq2}`
  - `ET` = 师德
  - `YYYY` = 年份
  - `region` = 区划代码（同编制/招聘模块）
  - `seq` = 同年同区划序号，2位
- 市直属时 region = `01`

### 区划代码表（同编制模块）

| 代码 | 区划 |
|------|------|
| 00 | 全市 |
| 01 | 市直属 |
| 09 | 鱼峰区 |
| 08 | 城中区 |
| 07 | 柳北区 |
| 10 | 柳南区 |
| 11 | 柳江区 |
| … | … |

## 7. 页面布局规范

### 列表页
- 两栏布局（批次卡片左 + 列表右），与招聘列表页一致
- 左侧：举报年份筛选 + 列表
- 右侧：状态筛选 + 表格
- 对齐项目 UI 规范（CSS token、topnav、sidebar、breadcrumb）

### 处理页 / 审批页
- 布局对齐 `staffing-form.html` 和审核编制使用申请页
- 两部分：基本信息区 + 处理结果区
- 审核页布局对齐 `审核编制使用申请页（主管单位视角）.html`
- 驳回弹窗：驳回意见 + 重新设定截止日期

### 详情页
- 布局对齐 `staffing-detail.html`
- 印章颜色：
  - 待分配 = 蓝色
  - 待处理 = 橙色
  - 待审批 = 橙色
  - 已完成 = 绿色
  - 已驳回 = 红色

## 8. 通知触发点

| 触发事件 | 通知对象 | 方式 |
|---------|---------|------|
| 市管理员指派 | 区管理员 | 站内消息 + 工作台待办 |
| 区提交处理结果 | 市管理员 | 站内消息 + 工作台待办 |
| 市驳回 | 区管理员 | 站内消息 + 工作台待办 |
| 市审批通过 | 区管理员 | 站内消息 |

## 9. 验收标准

1. 市管理员：手动录入举报 → 系统自动匹配区划 → 正常展示
2. 市管理员：上传Excel文件 → 解析预览 → 确认导入
3. 区属学校举报：指派 → 区处理 → 市审批通过 → 已完成
4. 区属学校举报：指派 → 区处理 → 市驳回 → 区重新处理 → 市审批通过
5. 市直属学校举报：市录入 → 市直接处理 → 自动归档
6. 学校管理员：可查看本校举报详情，不可操作
7. 教师：无入口
8. 附件上传：市录入和区处理均可上传附件
9. 字段名与现有模块一致
10. 页面布局与编制使用申请模块一致
