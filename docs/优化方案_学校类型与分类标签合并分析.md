# 优化方案：学校类型与学校分类标签合并分析

> 日期：2026-06-16 | 状态：方案确认中，暂未实施

---

## 1. 当前两个字段

| 字段 | 中文 | 必填 | 枚举值 |
|------|------|:--:|------|
| `schoolType` | 学校类型 | ✅ | `小学` `初中` `高中` `完中` `九年一贯制` `十二年一贯制` `中职` `幼儿园` `特殊教育`（9 个） |
| `schoolCategory` | 学校分类标签 | ❌ | `普通学校` `自治区示范高中` `自治区特色高中` `实验小学` `示范幼儿园`（5 个） |

## 2. 实际数据中的组合

| 学校 | schoolType | schoolCategory | 关系 |
|------|-----------|---------------|------|
| 柳州高级中学 | 高中 | 自治区示范高中 | 分类 = 高中子类 |
| 柳州市民族高中 | 高中 | 自治区特色高中 | 分类 = 高中子类 |
| 柳州市第三中学 | 高中 | 普通高中 | 分类 = 高中子类 |
| 柳州市第八中学 | 初中 | 普通学校 | 分类无额外信息 |
| 鱼峰区实验小学 | 小学 | 实验小学 | 分类 = 小学子类 |
| 城中区实验小学 | 小学 | 实验小学 | 分类 = 小学子类 |
| 鱼峰区机关幼儿园 | 幼儿园 | 示范幼儿园 | 分类 = 幼儿园子类 |

> **规律**：`schoolCategory` 是 `schoolType` 的子分类——自治区示范高中 ⊆ 高中，实验小学 ⊆ 小学，示范幼儿园 ⊆ 幼儿园。普通学校 = 无特殊分类。

## 3. 合并方案

### 方案 A：扩展 `schoolType` 枚举，删除 `schoolCategory`

将所有组合扁平化为一个枚举：

```
小学 / 实验小学 /
初中 / 
高中 / 普通高中 / 自治区示范高中 / 自治区特色高中 /
完中 / 九年一贯制 / 十二年一贯制 /
中职 / 幼儿园 / 示范幼儿园 / 特殊教育
```

**13 个枚举值**，一个字段搞定。

### 方案 B：保留两字段，`schoolCategory` 有条件显示

维持现状，但 `schoolCategory` 仅当 `schoolType ∈ {高中, 小学, 幼儿园}` 时显示，其他类型自动隐藏。

---

## 4. 方案 A 分析

### 优点

- 少一个表单字段，简化 UI
- 消除数据不一致：不会再出现 `schoolType=幼儿园, schoolCategory=自治区示范高中` 这种无意义组合
- 其他模块只需读一个字段

### 问题

| # | 问题 | 影响 | 严重度 |
|---|------|------|:--:|
| 1 | **台账模块卡片分开展示** | 台账「机构基础信息」卡片中学校类型和分类标签是分开两行显示的。合并后只需一行，实为改善 | 低 |
| 2 | **招聘岗位表单回填** | 招聘新建岗位时会从 SCHOOL_DATA 读取 `schoolType` 填入岗位字段。合并后需确保值一致 | 低 |
| 3 | **聘用手续 SCHOOL_DATA** | `employ-form.html` 中 `schoolType` 已存储了合并值如 `'自治区示范高中'`，与合并后一致 | 低 |
| 4 | **历史数据兼容** | 现有 localStorage 中的台账数据用的旧值，但可在读取时做迁移 | 低 |

> ~~岗位晋升/招聘按 `schoolType` 筛选~~：经代码审查，这两个模块仅将 `schoolType` 作为字段**存储和展示**，没有任何 `if (schoolType === '高中')` 之类的分组/筛选逻辑。此前的"高严重度"担忧不成立。

### 实际模块使用情况

| 模块 | `schoolType` 用途 | 有筛选逻辑？ |
|------|------------------|:--:|
| 岗位晋升 | 审核记录中存储展示 | ❌ 无 |
| 招聘 | 岗位表单回填 + 审核展示 | ❌ 无 |
| 聘用手续 | SCHOOL_DATA 字典读取 | ❌ 无 |
| 编制岗位台账 | 机构基础信息卡片展示 | ❌ 无 |

---

## 5. 修订结论

### 合并可行

两个字段合并没有实质障碍，各模块对 `schoolType` 的使用都是**只读展示**，不做逻辑判断。合并后 13 个枚举值：

```
小学 / 实验小学 /
初中 /
高中 / 普通高中 / 自治区示范高中 / 自治区特色高中 /
完中 / 九年一贯制 / 十二年一贯制 /
中职 / 幼儿园 / 示范幼儿园 / 特殊教育
```

### 合并收益

- 字段数 21→20
- 表单少一个下拉框
- 消除非法组合（如 幼儿园 + 自治区示范高中）

### 受影响文件

| 文件 | 改动 |
|------|------|
| `org-management.html` | 删除 `schoolCategory` 表单字段 + demo 数据字段 |
| `org-ledger-school.html` | demo 数据合并字段 |
| `org-ledger-admin.html` | 同上 |
| `org-ledger-detail.html` | 详情卡片合并展示行 |
| `recruit-form.html` | SCHOOL_DATA 去掉 `schoolCategory` |
| `employ-form.html` | SCHOOL_DATA 去掉 `schoolCategory` |

> 约 6 个文件，改动量可控。
