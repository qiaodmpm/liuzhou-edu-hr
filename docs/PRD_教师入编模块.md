# PRD：教师入编管理模块

> 版本: v2.0 | 日期: 2026-05-19 | 状态: 待开发

---

## 一、角色与职责

| 角色 | 职责描述 |
|------|---------|
| **校管理员** | 填写入编申请，提交申请，查看审核结果，对被驳回申请进行修改并重新提交 |
| **区管理员** | 审批本区学校提交的入编申请（通过/驳回），对已通过且未满 30 天的申请可修改结果为驳回 |
| **市管理员** | 审批市直属学校提交的入编申请；查看全市所有入编申请记录（只读）；导出已通过申请 |

---

## 二、权限矩阵

| 操作 | 校管理员 | 区管理员 | 市管理员 |
|------|:---:|:---:|:---:|
| 填写入编申请 | 本校 | — | — |
| 提交申请 | 本校 | — | — |
| 修改被驳回申请 | 本校 | — | — |
| 审批（通过/驳回） | — | 鱼峰区属学校 | 市直属学校 |
| 已通过→驳回（30天内） | — | 本区审批通过的 | 本市审批通过的 |
| 查看申请记录 | 本校 | 本区学校 | 全市所有学校（只读） |
| 导出已通过申请 | 本校 | 本区 | 全市 |

## 三、核心业务规则

### 3.1 申报模式：双轨制

校管理员填写入编申请时，必须选择编制类型（**单选**，提交后不可修改）：

| 维度 | 事业编（附件2） | 控制数（附件9） |
|------|--------------|--------------|
| 申报方式 | **实名制**，页面限制只能填 **1 人**后点提交 | **备案制**，一次可批量申报 **多人** |
| 申请人表单 | 单条详细表单 | 表格形式（支持动态增删行，不支持 Excel 导入） |
| 单位信息展示 | 核定编制数/现有人数/岗位构成/领导职数等 | 控制数类型/核定控制数/现有控制数人员等 |
| 材料附件 | 整个申请共享一套材料 | — |

### 3.2 申请流程

```
校管理员选择编制类型 → 查看单位信息 → 填写申请人信息 → 上传材料 → 提交
    ↓
  待审批
    ↓
  区属学校 → 区管理员审批
  市直属   → 市管理员审批
    ↓
  通过 → 已通过（终态，30天内原审批人可改为驳回）
  驳回 → 已驳回 → 校管理员修改 → 重新提交 → 待审批
```

- **编制类型提交后不可修改**
- 提交后**不可取消**，无草稿状态
- 若用户中途退出，填写内容不保存
- 被驳回的申请，校管理员可编辑原申请信息（事业编可修改个人表单；控制数可增删改人员表格），并重新上传/替换材料，重新提交后状态恢复为"待审批"，审批流程重新开始
- 系统记录修改痕迹（历史版本留存）

### 3.3 审核流程

- **单步审批**：区/市管理员直接审批，通过即为最终状态，无需二次录入
- 审批通过：填写审批意见（可选），申请状态变更为"已通过"
- 审批驳回：必须填写驳回原因，申请状态变更为"已驳回"，退回学校
- **控制数整体通过/驳回**，不支持部分通过

### 3.4 结果修改（30 天窗口）

- 审批通过后 **30 天内**，原审批人可将结果从"已通过"修改为"驳回"
- 修改后申请状态变为"待审批"，退回校管理员，审批流程重新开始
- 控制数申请修改后，原批次整体重新审批
- 超过 30 天，系统自动禁用"修改审核结果"按钮
- 此操作需填写驳回原因
- 无自动提醒，由审批人自行关注

### 3.5 市管理员只读

- 市管理员可查看**全市所有学校**的入编申请记录（含区属学校），支持按学校、编制类型、状态、申请时间筛选
- 对**非市直属**学校的申请，不显示任何审批操作按钮（不可通过、驳回、修改结果）
- 对市直属学校的待审批申请，可进行审批操作

### 3.6 数据导出

- 仅导出状态为"已通过"的申请，不支持导出待审批或已驳回
- 导出按钮放在入编管理列表页右侧操作区
- 导出格式：Excel（.xlsx）
- 导出内容：编制类型、申请时间、审批时间、人员明细（事业编含详细字段；控制数含人员列表）
- 不导出附件材料

### 3.7 消息通知

- 申请审批通过/驳回后，系统向校管理员推送站内消息（或短信通知）
- 驳回时附带驳回原因
- 控制数批次整体通知，不逐人通知

## 五、详细功能规格

### 5.1 单位信息展示（只读）

入编申请页面顶部根据选择的**编制类型**展示不同的单位信息，数据自动带出，**不可编辑**。

#### 事业编类型

保持现状（核定编制数、现有人数、岗位构成、领导职数等）。

#### 控制数类型

| 字段名称 | 说明 |
|---------|------|
| 单位名称 | 学校全称，自动带出 |
| 控制数类型 | 下拉选择：中小学校聘用教师控制数 / 中职中专学校教职人员控制数 / 高等职业学校教职人员控制数 / 公立医院聘用人员控制数 |
| 核定控制数 | 学校核定的控制数总量，自动带出 |
| 现有控制数人员 | 当前已使用的控制数人数，自动带出 |
| 本次备案控制数人员 | **系统根据填写的申请人数量自动计算** |
| 备案后控制数人员 | 现有控制数人员 + 本次备案控制数人员，**自动计算** |

### 5.3 材料清单与附件上传

#### 5.3.1 通用附件规则

- 支持格式：Word（.doc/.docx）、Excel（.xls/.xlsx）、PDF（.pdf）、图片（.jpg/.jpeg/.png/.bmp/.gif）
- 单个文件大小上限：**10 MB**
- 不支持格式：压缩包（.zip/.rar/.7z 等）、可执行文件等
- **每项材料可上传多个文件**（最多 10 个/项）
- **必传项校验**：必传材料未上传或上传失败时，无法提交申请

#### 5.3.2 事业编材料清单

| 材料名称 | 是否必传 | 条件说明 |
|---------|:---:|------|
| 身份证扫描件 | 是 | — |
| 学历学位证书 | 是 | — |
| 教师资格证 | 是 | — |
| 原单位同意调出证明 | 条件必传 | 若入编方式为"调动"则必传 |
| 公开招聘相关文件 | 条件必传 | 若入编方式为"统一公开招聘"则必传 |
| 其他补充材料 | 否 | — |

#### 5.3.3 控制数材料清单

| 材料名称 | 是否必传 | 条件说明 |
|---------|:---:|------|
| 控制数使用申请表（盖章扫描件） | 是 | 固定模板，需盖章 |
| 人员花名册（模板填写后上传） | 是 | Excel 格式，必须使用系统提供的模板 |
| 拟聘人员身份证明材料 | 否 | 不支持压缩包，请逐人逐项上传（身份证、学历证等） |
| 学校党委/校务会讨论通过会议纪要 | 是 | 需签字盖章 |
| 其他补充材料 | 否 | — |

### 5.4 提交与申请管理

| 功能 | 描述 |
|------|------|
| **提交申请** | 校验所有必填字段及附件后，生成唯一申请编号（规则：RN + 年月日 + 流水号，如 RN20260519001），状态为"待审批" |
| **查看申请记录** | 校管理员可查看本校所有入编申请记录（待审批/已通过/已驳回），支持按申请时间、编制类型筛选 |
| **查看审批详情** | 查看单条申请的审批节点进度、审批意见、审批时间、编制类型、申请人信息及上传的材料（支持在线预览及下载） |
| **修改被驳回申请** | 审批被驳回后，校管理员可编辑原申请信息（事业编可修改个人表单；控制数可增删改人员表格），并重新上传/替换材料，重新提交。系统记录修改痕迹（历史版本留存） |
| **重新提交** | 修改完成后重新提交，状态恢复为"待审批"，审批流程重新开始 |
| **不支持取消申请** | 待审批状态下无"取消"按钮，申请一旦提交不可撤销 |
| **无草稿功能** | 填写后必须立即提交；若用户中途退出，填写内容不保存 |

---

### 5.5 审批管理（区管理员 & 市管理员）

#### 5.5.1 待审批申请列表

- **区管理员**：展示本区所有学校提交的"待审批"申请，支持按学校、编制类型、申请时间筛选
- **市管理员**：展示市直属学校提交的"待审批"申请
- 控制数类型申请在列表中显示汇总信息（如"柳州高级中学控制数入编申请（5人）"）

#### 5.5.2 审批操作

- **审批通过**：填写审批意见（可选），申请状态变更为"已通过"。事业编通过单人；控制数整体通过整个批次。**审批通过后，本学校可用编制数/控制数自动减去对应人数**
- **审批驳回**：必须填写驳回原因，申请状态变更为"已驳回"，退回学校。控制数批次整体驳回，**不支持部分通过**

#### 5.5.3 修改审核结果（30 天内）

- 对审批通过未满 30 天的申请，原审批人可手动将结果修改为"驳回"
- 修改后状态变为"待审批"，申请重新进入审批流程
- 超过 30 天后，系统自动禁用"修改审核结果"按钮
- 无自动提醒，由审批人自行关注

#### 5.5.4 市管理员查看权限（只读）

- 可查看全市所有学校（含区属）的入编申请记录
- 支持按学校、编制类型、状态、申请时间筛选
- 无任何审批操作按钮（不可通过、驳回、修改结果），仅查看

### 5.6 数据导出（仅已通过申请）

| 导出角色 | 导出范围 | 导出内容 |
|---------|---------|---------|
| 校管理员 | 本校已通过申请 | Excel 列表 |
| 区管理员 | 本区已通过申请 | 同上 |
| 市管理员 | 全市已通过申请 | 同上 |

导出字段包括：编制类型、申请时间、审批时间、人员明细（事业编含详细字段；控制数含人员列表）。**不导出附件材料**。

## 六、数据结构

### 6.1 申请记录

```
{
  id,                    // 申请编号（RN+年月日+流水号，如 RN20260519001）
  schoolName,            // 学校名称
  schoolType,            // 市直属 | 鱼峰区属
  staffingType,          // career(事业编) | control(控制数) — 提交后不可修改
  controlType,           // 控制数类型（仅 staffingType=control 时必填）
  applicants: [...],     // 申请人列表（事业编固定1人）
  materials: [...],      // 上传材料清单
  status,                // pending(待审批) | approved(已通过) | rejected(已驳回)
  submitTime,            // 提交时间
  approveTime,           // 审批通过时间（用于30天窗口计算）
  approver,              // 审批人
  approverRole,          // 审批人角色（district/city）
  opinion,               // 审批意见
  rejectReason,          // 驳回原因
  timeline: [...],       // 申报履历（含修改痕迹）
  versionHistory: [...], // 历史版本（被驳回后修改的旧版本留存）
}
```

### 6.2 控制数申请人

```
{
  name,          // 姓名
  gender,        // 男 | 女
  idCard,        // 身份证号（18位）
  docNumber,     // 依据文号
  entryMethod,   // 增人形式
  materials: [...] // 该申请人独立的材料附件
}
```

### 6.3 事业编申请人

```
{
  name,              // 姓名
  gender,            // 男 | 女
  politics,          // 政治面貌
  ethnicity,         // 民族
  nativePlace,       // 籍贯
  assignPosition,    // 拟分配岗位
  education,         // 文化程度
  graduateInfo,      // 毕业院校及专业
  previousJob,       // 原工作单位
  cadreOrWorker,     // 干部 | 工人
  orgNature,         // 单位性质
  title,             // 职务职称
  fundingSource,     // 经费来源
  spouseName,        // 配偶姓名
  spouseWorkUnit,    // 配偶工作单位
  entryMethod,       // 入编方式
  docNumber,         // 依据文号
  reason,            // 申请使用编制的主要理由（≤500字）
}
```

## 七、与原需求的主要变更

| 变更项 | 旧规则 | 新规则 |
|--------|-------|-------|
| 批次机制 | 有批次（EB2026-001等） | **去除批次**，学校自主申报 |
| 编制类型 | 仅控制数 | **双轨**：事业编（实名制）+ 控制数（备案制），提交后不可修改 |
| 审核步骤 | 学校审核 → 教育局审核（两步） | 教育局审批（**单步**） |
| 结果修改 | 无 | 30天内可改为驳回 |
| 市管理员 | 查看+审批 | 市直属审批 + 全市只读 |
| 导出范围 | 无限制 | 仅已通过 |
| 草稿 | 未明确 | **无草稿**，提交后不可取消，中途退出不保存 |

- 支持格式：Word（.doc/.docx）、Excel（.xls/.xlsx）、PDF（.pdf）、图片（.jpg/.jpeg/.png/.bmp/.gif）
