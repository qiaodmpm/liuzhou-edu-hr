## 三、四步进度追踪

```
Step 1              Step 2              Step 3              Step 4
学校提交            一审：材料审核       学校提交人社结果      二审：人社确认
───────            ───────────         ──────────────      ────────────
校管理员            区/市管理员          校管理员              区/市管理员
在线填写审核表       审核材料             录入人社局核准结果      确认最终数据
提交申报            通过 / 驳回          上传批复PDF           可修改数据
                                                             确认通过（终态）
  ●─────────────────●──────────────────●──────────────────●
  done              done               done               done  ← completed
  done              done               done            current  ← second_review
  done              done             current           pending  ← first_approved
  done            current            pending           pending  ← first_review
  done            rejected           ──────            ──────  ← first_rejected
```

## 四、角色权限矩阵

| 状态 | 校管理员 | 区管理员（区属） | 市管理员（市直属） |
|------|:--:|:--:|:--:|
| 无记录 | 新建申请 | 查看未提交列表 / 提醒 | 查看未提交列表 / 提醒 |
| `first_review` | 查看 | **审核（通过/驳回）** | **审核（通过/驳回）** |
| `first_approved` | **录入人社结果** / 导出 | 查看 | 查看 |
| `first_rejected` | **编辑重提** | 查看 | 查看 |
| `second_review` | 查看 | **确认（可修改数据）** | **确认（可修改数据）** |
| `completed` | 查看 / 下载PDF | 查看 | 查看 |

## 五、二审（Step 4）特殊规则

与一审不同，二审有以下特点：

1. **不可驳回**：二审只有「确认通过」按钮，没有驳回操作
2. **可修改数据**：审核人可以修改最终结果中的任意数字
3. **三列对比视图**：

```
┌──────────┬──────────┬──────────┐
│ 原始申报  │ 人社核准  │ 最终结果  │
│ (只读)   │ (只读)   │ (可编辑)  │
├──────────┼──────────┼──────────┤
│   80     │   78     │  [78]    │  ← 蓝色边框=已修改
│   15     │   15     │   15     │  ← 未修改
└──────────┴──────────┴──────────┘
```
