4 统计逻辑

📐 计数规则
  • 遍历学校所有教师账号
  • isHighlandMember === true 的教师 → 按岗位等级计入 小高地岗位 行
  • isHighlandMember === false 的教师 → 按岗位等级 + 编制类型计入实名编/控制数行
  • 小高地成员数 不重复计入 实名编/控制数行（人数不翻倍）
📋 示例数据解读

柳州市第八中学 专技七级 共 8 人：

教师编制小高地成员计入行
张美华实名编是小高地岗位
刘×6人实名编否实名编
王×1人控制数否控制数
合计核实实名编 6+1(小高地) + 控制数 1 = 8 ✓

6 方案总结

维度说明
新增字段2 个布尔字段：学校级 isHighlandSchool + 教师级 isHighlandMember
字段维护机构管理 维护学校标记（市/区管理员）；账号管理 维护成员标记（市/区管理员）
统计规则isHighlandMember = true → 不计入实名编/控制数行 → 单独计入小高地行
影响范围2 个新增字段 + 汇总表统计逻辑（已有小高地行结构，只需补数据源）
向后兼容默认 false，未打标的学校和教师行为完全不变
