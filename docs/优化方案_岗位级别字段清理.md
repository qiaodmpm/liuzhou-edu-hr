# 优化方案：岗位级别 `schoolType` 字段清理

> 日期：2026-06-16 | 状态：方案确认中，暂未实施

---

## 1. 问题

岗位晋升和招聘模块中，岗位/记录对象上存储了 `schoolType` 字段，但该字段**并非岗位本身的属性**，而是从所属学校复制过来的冗余数据。

### 现行代码

```javascript
// recruit-form.html:595 — 新建岗位时从学校数据复制
pos = {
  schoolName: currentSchool,
  schoolType: sd.schoolType || '',  // ← 冗余：等于学校.schoolType
  positionName: '',
  ...
};

// recruit-form.html:1317 — 还被列为岗位字段之一
if (type === 'independent') return ['city','schoolName','schoolType',...];
```

```javascript
// promote-audit-second.html — 审核记录中也存了一份
{ schoolName: '柳州高级中学', schoolType: '自治区示范高中', status: '...' }
```

### 问题本质

```
岗位.schoolType  ≡  学校.schoolType（通过 schoolName 关联）
```

这不是岗位自身的属性——它只是从学校复制过来的。既然 `schoolName` 已经在岗位对象上，`schoolType` 可以随时通过 `schoolName` 查到。

## 3. 优化方案

### 方案：删除岗位级别的 `schoolType`，改为从学校查找

**核心思路**：岗位对象上只存 `schoolName`，需要 `schoolType` 时通过工具函数查找。

```javascript
// 新增工具函数
function getSchoolType(schoolName) {
  var dir = JSON.parse(localStorage.getItem('org_directory') || '[]');
  for (var i = 0; i < dir.length; i++) {
    if (dir[i].orgName === schoolName) return dir[i].schoolType;
  }
  return '';
}
```

### 3.1 招聘模块改动

```diff
// recruit-form.html
- pos = { ..., schoolType: sd.schoolType || '', ... };
+ pos = { ..., schoolName: currentSchool, ... };

// 表单中"学校类型"改为只读，从学校数据自动填充
- h += formField('学校类型', 'schoolType_' + idx, pos.schoolType, 'text');
+ h += formField('学校类型', 'schoolType_' + idx, getSchoolType(pos.schoolName), 'text');

// 审核详情
- h += fv('学校类型', pos.schoolType);
+ h += fv('学校类型', getSchoolType(pos.schoolName));
```

### 3.2 岗位晋升模块改动

```diff
// 审核记录
- { schoolName: '柳州高级中学', schoolType: '自治区示范高中', ... }
+ { schoolName: '柳州高级中学', ... }

// 展示时
- 直接读 record.schoolType
+ 调用 getSchoolType(record.schoolName)
```

---

## 4. 收益

| 维度 | 说明 |
|------|------|
| **数据一致性** | 学校类型只有一处权威来源（机构目录），不会出现岗位记录的 `schoolType` 和学校不同步 |
| **字段减负** | 岗位对象少一个冗余字段，新建岗位时少一次复制操作 |
| **语义清晰** | 岗位对象上不再有名为 `schoolType` 的字段（容易误解为"岗位类型"），统一通过学校名称查找 |
| **独立招聘特殊处理** | 独立招聘的岗位字段列表中移除 `schoolType`，由系统自动填充 |

## 6. 补充建议

如果将来机构目录被全站统一引用，`getSchoolType()` 这类查找函数可以抽取为公共工具，所有模块共享，进一步减少 SCHOOL_DATA 等模块级字典的维护。
