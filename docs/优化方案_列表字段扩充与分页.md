## 二、分页方案

### 2.1 分页参数

| 参数 | 默认值 | 说明 |
|------|:--:|------|
| `pageSize` | 10 | 每页条数 |
| `currentPage` | 1 | 当前页码 |

### 2.2 分页栏样式（对齐项目规范）

参照 `staffing-application.html` 的分页组件：

```
┌─ 列表卡片 ─────────────────────────────────────────────┐
│  学校编号 │学校名称│...│状态│操作                        │
│  ... 10 行数据 ...                                     │
├────────────────────────────────────────────────────────┤
│  共 11 条    ◀  1  2  ▶     10 条/页                    │
└────────────────────────────────────────────────────────┘
```

### 2.3 CSS（对齐项目规范）

```css
.pagination {
  display: flex; justify-content: space-between; align-items: center;
  padding: 12px 18px; font-size: 12px; color: var(--text-secondary);
}
.pagination-btns { display: flex; gap: 4px; }
.pagination-btns button {
  width: 32px; height: 32px; border: 1px solid var(--border);
  background: #fff; border-radius: 6px; cursor: pointer; font-size: 12px;
  transition: var(--transition); color: var(--text);
}
.pagination-btns button:hover { border-color: var(--primary); color: var(--primary); }
.pagination-btns button.active { background: var(--primary); color: #fff; border-color: var(--primary); }
```

> 替换当前 `org-ledger-admin.html` 中简化的 `.pagination` CSS（第154-157行）。

### 2.4 分页栏 HTML

```html
<div class="pagination">
  <span>共 N 条</span>
  <div class="pagination-btns">
    <button onclick="goPage(p-1)">◀</button>
    <!-- 页码按钮动态生成 -->
    <button onclick="goPage(p+1)">▶</button>
  </div>
  <span>10 条/页</span>
</div>
```

### 2.5 分页逻辑

```javascript
var currentPage = 1;
var pageSize = 10;

function goPage(p) {
  var totalPages = Math.ceil(filteredLedgers.length / pageSize);
  if (p < 1 || p > totalPages) return;
  currentPage = p;
  renderList(); // 只渲染当前页的数据行，不重建整个卡片
}

// 在 renderList 中：
var startIdx = (currentPage - 1) * pageSize;
var endIdx = Math.min(startIdx + pageSize, filteredLedgers.length);
var pageData = filteredLedgers.slice(startIdx, endIdx);
// 用 pageData 渲染表格行
```

### 2.6 分页重置

切换筛选条件（状态标签、区域、搜索）时，`currentPage` 重置为 1：

```javascript
// 各筛选 onchange/oninput 中：
filterStatus = 'all'; renderList();  // 已自动触发 currentPage = 1
```

## 三、列表页 UI 样式对齐项目规范

### 3.1 当前问题

`org-ledger-admin.html` 的列表区域使用 `org-ledger-detail.html` 的 CSS（在创建时复制了详情页的样式），存在以下不规范：

| 问题 | 当前 | 应改为 |
|------|------|--------|
| 列表卡片类名 | `.list-card` | ✅ 已正确 |
| 表格类名 | `.list-table` | ✅ 已正确 |
| 表头样式 | `background: #F8FAFC` | ✅ 已正确 |
| 操作列链接 | `.action-links a` 带 `text-decoration: none` | 需增加 `.action-links a:hover` 下划线 |
| 空状态 | 简单文本 `暂无匹配的学校台账` | 需对齐项目 `.empty-state` 模式 |
| table 圆角溢出 | 无处理 | 需 `.list-card` 配合 `overflow: hidden` |

### 3.2 对齐改动清单

| # | 改动项 | 说明 |
|---|--------|------|
| 1 | `.action-links a` 增加 `font-size: 12px; color: var(--primary); text-decoration: none;` | 对齐 staffing-application |
| 2 | `.action-links a:hover` 增加 `text-decoration: underline;` | 交互反馈 |
| 3 | 空状态替换为标准组件 | 图标 + "暂无数据" 两行文本 |
| 4 | `.pagination` CSS 替换为完整版 | 含 `.pagination-btns` |
| 5 | 表头列宽定义 | `th` 增加 `style="width:XXpx"` 或使用 `colgroup` |
