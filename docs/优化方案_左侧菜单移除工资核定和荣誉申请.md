> 日期：2026-06-17 | 状态：✅ 已实施

---

## 1. 改动范围概述

需要从全站左侧菜单中移除 `工资核定申请` 和 `荣誉申请` 两个菜单项，涉及以下三类改动：

| 类别 | 说明 | 影响文件数 |
|------|------|:--:|
| A | 侧边栏 ROLES 数据中删除菜单项 | ~15 |
| B | `sidebarClick` 中删除对应跳转逻辑 | ~6 |
| C | 其他引用文字调整 | 2 |

## 3. 具体改动模式

### 模式 A1：管理员 ROLES 人事管理组（重复出现在 ~15 个文件 × 3 角色）

```javascript
// 改前
{ name: '人事管理', items: [
  { id: 'retire', label: '退休呈报' },
  { id: 'salary', label: '工资核定申请' },   // ← 删除此行
  { id: 'ethics', label: '师德师风举报' },
  { id: 'honor', label: '荣誉申请' }          // ← 删除此行
]}

// 改后
{ name: '人事管理', items: [
  { id: 'retire', label: '退休呈报' },
  { id: 'ethics', label: '师德师风举报' }
]}
```

### 模式 A2：教师 ROLES 业务申请组（重复出现在 ~12 个文件）

```javascript
// 改前
groups: [
  { name: '业务申请', items: [
    { id: 'promote', label: '岗位晋升申请' },
    { id: 'ethics', label: '师德师风举报' },
    { id: 'honor', label: '荣誉申请' }         // ← 删除此行
  ]}
]

// 改后
groups: [
  { name: '业务申请', items: [
    { id: 'promote', label: '岗位晋升申请' },
    { id: 'ethics', label: '师德师风举报' }
  ]}
]
```

### 模式 B：sidebarClick 删除跳转逻辑（~6 个文件）

## 5. 实施策略

建议使用 Node.js 批量替换脚本，按以下正则模式处理：

**Step 1**：删除 `{ id: 'salary', label: '工资核定申请' },`（含尾部逗号变体）

**Step 2**：删除 `{ id: 'honor', label: '荣誉申请' }`（含尾部逗号变体）

**Step 3**：删除 sidebarClick 中的 salary/honor 跳转行

**Step 4**：手动调整 `index.html` 和 `personal-center.html` 的特殊文字

预计开发时间：**1h**（含脚本 30min + 手动调整 20min + 验证 10min）
