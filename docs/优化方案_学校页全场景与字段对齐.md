# 优化方案：学校页全业务场景覆盖 + 主管单位等级分布补充

> 日期：2026-06-15 | 状态：方案确认中，暂未实施

---

## 一、学校页缺少"创建"环节

### 1.1 现状

11 所内置学校全部有台账数据，切换学校后永远看不到"建立台账"的初始创建场景。

### 1.2 方案

新增「柳江区实验中学」→ 无台账数据，切换到此学校时显示"建立台账"引导页：

| 学校 | 状态 | 覆盖场景 |
|------|:--:|------|
| 柳江区实验中学 | 未建立 | 引导页 → 创建 |
| 柳州市第三中学 | 待提交 | 编辑 + 提交 |
| 柳州市第八中学 | 待审核 | 只读等待 |
| 柳州市第一中学 | 已生效 | 查看 + 编辑 |

## 二、主管单位看不到等级分布明细

### 2.1 问题

`org-ledger-detail.html` 的岗位结构卡片只渲染了分类汇总表：

```
┌─ 📌 岗位结构 ────────────────────────┐
│  小高地岗位数    总量控制数    岗位总量  │
│  类别        │ 核定岗位数 │ 实有人数   │
│  管理岗位    │    8     │    4      │
│  专业技术岗位│   80     │   68      │
│  工勤技能岗位│   16     │   22      │
└──────────────────────────────────────┘  ← 缺少等级分布！
```

学校编辑表单（`org-ledger-school.html` renderEditForm）有这些等级分布，但主管单位详情页缺失：
- 管理岗位等级分布（五级~十级）
- 专业技术岗位等级分布（正高/副高/中级/初级 × 等级）
- 工勤技能岗位等级分布（一级~五级 + 普通工）

### 2.2 方案

详情页岗位结构卡片下方补充三级等级分布，与学校填写的字段完全对齐：

```
┌─ 📌 岗位结构 ────────────────────────────────────┐
│  小高地：0    总量控制数：104    岗位总量：104      │
│                                                  │
│  类别        │ 核定岗位数 │ 实有人数                │
│  管理岗位    │     8     │    4                   │
│  专业技术岗位│    80     │   68                   │
│  工勤技能岗位│    16     │   22                   │
│                                                  │
│  管理岗位等级分布                                  │
│  五级1  六级2  七级2  八级2  九级1  十级0           │
│                                                  │
│  专业技术岗位等级分布                              │
│  正高0 副高15 中级45 初级20                       │
│  正高:三级0 四级0  副高:五级3 六级6 七级6          │
│  中级:八级14 九级18 十级13  初级:十一8 十二8 十三4 │
│                                                  │
│  工勤技能岗位等级分布                              │
│  一级0  二级1  三级3  四级6  五级8  普通工4        │
└──────────────────────────────────────────────────┘
```

### 2.3 完整字段对齐

| 字段区 | 学校编辑 | 主管审核/查看 | 对齐？ |
|--------|:--:|:--:|:--:|
| 机构基础信息 | 8 字段 | 8 字段 | ✅ |
| 编制信息 | 事业编 4 + 控制数 4 | 同 | ✅ |
| 岗位分类 | 3 类 × 核定/实有 | 同 | ✅ |
| 管理岗位等级 | 5-10 级 | **缺失 → 补充** | ❌→✅ |
| 专技岗位等级 | 正高/副高/中级/初级 | **缺失 → 补充** | ❌→✅ |
| 工勤等级 | 1-5 级 + 普通工 | **缺失 → 补充** | ❌→✅ |
| 领导职数 | 汇总 + 厅处科 | 同 | ✅ |
