## 1. 模块概述

### 1.1 业务背景

教师因调动、退休、辞职、辞退、开除、亡故等原因退出编制时，学校需向编办提交出编核减申请，将相关人员从编制名册中移除，释放编制名额。

### 1.2 业务目标

- 校管理员在线提交出编申请（双轨：事业编 / 控制数）
- 主管单位一级审批
- 审批通过后自动更新在编人员名册、编制统计数据、生成出编台账
- 出编结果永久锁定，不可修改

### 1.3 核心特征

| 特征 | 说明 |
|------|------|
| 双轨制 | 事业编（8 种出编类型）/ 控制数（4 种出编类型） |
| 一级审批 | 学校提交 → 主管单位直接终审 |
| 无修改窗口 | 审批通过后结果**永久锁定**，不可撤销，不可修改 |
| 批量操作 | 多人表格，一次提交多人出编 |
| 自动联动 | 审批通过后自动更新在编名册、编制统计、生成台账、冻结账号 |

## 3. 审批流程

```
校管理员提交出编申请
        │
        ▼
 status = pending
        │
        ▼
主管单位终审 ──→ 驳回 → status = rejected（学校修改重提）
        │
        ▼ 通过
 status = approved
        │
        ▼
自动执行：
  1. 从在编名册中标记"已出编"
  2. 更新编制统计（实有人数 -N，可用编制 +N）
  3. 生成出编台账记录
  4. 冻结教师系统账号
        │
        ▼
  结果永久锁定（不可修改、不可撤销）
```

### 3.1 状态枚举

| 状态 | 含义 | 可操作角色 |
|------|------|-----------|
| `pending` | 待审核 | 主管单位（审核） |
| `approved` | 已通过（永久锁定） | 全部（只读，不可修改） |
| `rejected` | 已驳回 | 校管理员（修改重提） |

## 6. 业务规则

### 6.1 双轨差异

| 规则 | 事业编 | 控制数 |
|------|--------|--------|
| 出编类型数 | 8 种 | 4 种 |
| 编制本序号 | 必填（除离退休亡故） | 不需要 |
| 姓名输入 | 从在编名册下拉选择，自动填充 | 从在编名册下拉选择，自动填充 |
| 离退休亡故 | 独立类型，姓名自由输入 | 不含此类型 |

### 6.2 审批后自动联动

审批通过后系统自动执行：

1. **在编名册更新**：将出编人员标记为 `status: 'frozen'`，备注 `reason: 'exit'`
2. **编制统计更新**：实有在编人数 -N，可用编制数 +N
3. **出编台账生成**：写入 `exit_ledger` 到 localStorage
4. **账号冻结**：对应教师账号 `status: 'frozen'`，禁用登录

### 6.3 结果不可修改

- 与入编模块不同，出编**没有** 30 天修改窗口
- 审批通过即永久生效，不可撤销
- 如确需回退，需走线下流程

### 6.4 市管理员只读限制

- 市管理员可查看全市所有出编记录（含区属）
- 但**只有**市直属学校的记录才显示审批按钮

### 6.5 姓名选择规则

- 姓名从当前在编人员列表（`DEMO_CURRENT_STAFF`）中下拉选择
- 选择后自动填充性别和身份证号
- 离退休人员亡故核减类型不在此列，使用自由文本输入

### 6.6 导出规则

- 仅 `approved` 状态记录可导出
- 导出格式：CSV

## 7. 页面交互说明

### 7.1 新建/编辑申请页（exit-form.html）

- 顶部类型切换：事业编 / 控制数
- 单位信息区（只读）：编制类型/控制数类型、核定数、实有人数、剩余可用数
- 多人表格：
  - 列：序号、姓名（下拉选择）、性别（自动填充）、身份证（自动填充）、文件编号、出编类型（下拉）、编制本序号（事业编）、材料
  - 支持增删行，每次添加一行
  - 不支持 Excel 导入
- 材料上传区：每行独立的材料清单，按出编类型动态展示
- 底部：提交按钮 + 取消按钮

### 7.2 学校管理列表

- 筛选：状态、出编类型、年度
- 表格列：申请编号、出编人数、编制类型、出编类型、状态、提交时间、操作
- 操作：查看详情、修改（驳回后）

### 7.3 主管单位审核页（exit-audit.html）

- 申请信息展示（只读）
- 出编人员表格（只读）
- 材料预览和下载
- 操作区：通过按钮 + 驳回按钮（带驳回原因输入框）
- 无"修改审核结果"功能（区别于入编）
