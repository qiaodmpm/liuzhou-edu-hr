# 优化方案：学校管理员编辑 & 审核流程

> 日期：2026-06-18 | 状态：✅ 已实施

---

## 1. 现状

| 角色 | 查看 | 编辑 | 审核 |
|------|:--:|:--:|:--:|
| 市管理员 | ✅ 列表 + 查看页 | ✅ 直接生效 | — |
| 区管理员 | ✅ 列表 + 查看页（仅本区） | ✅ 直接生效 | — |
| 校管理员 | ❌ 看不到机构管理 | ❌ | — |

> 管理员编辑即时生效，无审核环节。

---

## 2. 优化目标

1. 校管理员可查看本校信息（与查看页布局一致）
2. 校管理员可编辑本校所有字段（**校管理员字段 + 所属区域锁定**）
3. 编辑保存后进入待审核状态，不立即生效
4. 主管单位审核时可重新编辑 → 审核通过
5. 主管单位审核时**没有驳回操作**，只有编辑 + 审核通过
6. 所有编辑、审核操作记录到更改记录

---

## 3. 角色权限矩阵

| 操作 | 市管理员 | 区管理员 | 校管理员 |
|------|:--:|:--:|:--:|
| 查看学校 | ✅ 全部 | ✅ 本区 | ✅ 本校 |
| 直接编辑（即时生效） | ✅ 全部 | ✅ 本区 | ❌ |
| 提交审核 | — | — | ✅ |
| 审核（编辑 + 通过） | ✅ 仅市直属 | ✅ 本区 | — |
| 校管理员字段 | ✅ 可编辑 | ✅ 可编辑 | 🔒 锁定 |

### 3.1 管辖范围

| 管理员 | 只读范围 | 可编辑范围 | 不可编辑 |
|--------|----------|-----------|----------|
| 市管理员 | 全市 | 全市所有学校 | — |
| 区管理员 | 本区 | 仅本区内学校 | 其他区 / 市直属 / 市教育局 |

> - **下级可管**：市 > 全市；区 > 本区
> - **同级不可管**：鱼峰区 ↛ 城中区
> - **上级不可管**：区 ↛ 市直属
> - 违反管辖 → 不显示编辑/停用按钮

### 3.2 审核权限

| 待审核机构 | 可审核人 |
|-----------|----------|
| 市直属学校 | 市管理员 |
| 区属学校 | 本区管理员 |

> - **市管理员审核市直属**：只审核市直属学校提交，不审核区属学校
> - **区管理员审核本区**：只审核本区学校提交，不跨区审核

## 4. 数据模型

### 4.1 新增字段

```javascript
{
  // 现有字段不变
  orgId: '...',
  // ...

  // 新增（无 draft，无驳回）
  reviewStatus: null,      // null | 'pending'
  reviewedBy: '',          // 最近审核人
  reviewedAt: ''           // 最近审核时间
}
```

> - 只有两个状态：`null`（正常）和 `'pending'`（待审核）
> - 没有驳回状态，没有驳回原因字段
> - 主管单位审核时只有编辑 + 审核通过，不满足就继续编辑直到满足再通过

### 4.2 状态流转

```
              学校编辑提交
active ────────────────────→ pending
  ↑                             │
  │                             │
  └──────── 主管审核通过 ────────┘
         （可编辑后通过）
```

| 触发 | 操作 | 状态变化 |
|------|------|:--:|
| 学校提交编辑 | 数据写入 + 设 pending | null → pending |
| 主管审核通过 | 数据生效 + 设为 null | pending → null |
| 主管直接编辑 | 数据即时生效 | null → null |

### 4.3 更改记录类型

| type | 触发 | 记录内容 |
|------|------|----------|
| `submit_review` | 学校提交审核 | 变更字段对比 |
| `approve` | 管理员审核通过 | 审核人 + 管理员变更（如有） |
| `edit` | 管理员直接编辑 | 变更字段对比 |
| `create` | 新建机构 | — |
| `disable` | 停用 | — |
| `enable` | 启用 | — |

## 7. 交互流程

### 7.1 学校编辑提交

```
查看页 → "编辑" → 进入编辑模式
  → 编辑字段（校管理员/所属区域锁定）
  → "提交审核"
  → 快照对比 → changeLog 追加 submit_review
  → reviewStatus = 'pending'
  → 返回查看页 🟡 待审核
```

> 提交时用进入编辑页时的快照与表单当前值对比，生成 changes。

### 7.2 主管审核

```
列表待审核 Table → "审核" → 审核页
  → 查看变更摘要卡片
  → 可选：编辑字段
  → "审核通过"
  → reviewStatus = null
  → 对比当前数据与 submit_review 提交时数据
  → changeLog 追加 approve（含管理员变更）
```

## 8. 字段锁定规则

| 字段 | 学校编辑 | 主管审核 |
|------|:--:|:--:|
| 单位名称 | ✅ | ✅ |
| 单位简称 | ✅ | ✅ |
| 所属区域 | 🔒 | ✅ |
| 单位级别 | ✅ | ✅ |
| 组织类型 | ✅ | ✅ |
| 学校类型（cond） | ✅ | ✅ |
| 学校分类标签 | ✅ | ✅ |
| 单位性质 | ✅ | ✅ |
| 单位类型（公益分类） | ✅ | ✅ |
| 经费类型 | ✅ | ✅ |
| 统一社会信用代码 | ✅ | ✅ |
| 校管理员 | 🔒 | ✅ |
| 学校地址 | ✅ | ✅ |
| 联系电话 | ✅ | ✅ |
| 邮编 | ✅ | ✅ |

### 8.1 编制岗位台账 — 机构基础信息只读

台账模块（`org-ledger-detail.html?school=...`）的"机构基础信息"区域**全部只读**。

| 台账字段 | 可编辑 | 如需编辑 |
|----------|:--:|------|
| 单位全称、所属区域、学校类型、机构级别、单位性质、经费形式、信用代码 | ❌ | 从机构管理编辑 |

台账页机构基础信息区域添加提示：
> 💡 机构基础信息如需修改，请前往 **[机构管理](org-management.html)** 模块编辑。

台账机构基础信息从 `org_directory` 读取（与机构管理同源），确保数据一致。

## 9. 更改记录完整类型

```
  ● 创建机构        — 机构首次创建
  ● 提交审核        — 学校提交编辑（含变更对比）
  ● 审核通过        — 主管审核通过（含主管变更）
  ● 编辑机构        — 管理员直接编辑（即时生效）
  ● 停用机构        — 管理员停用
  ● 启用机构        — 管理员启用
```
