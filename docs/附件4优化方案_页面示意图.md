## 三、关键视觉元素说明

### 1. Step Bar（步骤指示器）

```
┌──────────────────────────────────────────────────────┐
│                                                      │
│   (✓)  ───────  (●)  ───────  (○)                   │
│  选择业务类型     填写岗位及人员     审核汇总           │
│  （已完成）       （当前步骤）       （待处理）          │
│                                                      │
└──────────────────────────────────────────────────────┘
```

- 三个圆点 + 连接线，利用已有 `.step-bar` CSS
- 业务类型选定后自动高亮步骤②
- 步骤③始终可访问（不阻塞），有已确认岗位时高亮
- 不强制用户按步骤操作，仅作视觉引导

### 2. 区域分隔

```
─── 📋 填报区：拟聘岗位及人员信息 ───
        ↑ 左对齐的 section 标题
        ↑ 下划线分隔 + 图标
```

与现有 `.form-card` 不同，这是一个横向分隔带，用 `border-bottom` + 标题把页面切成三个逻辑区。视觉上类似：

```
───────────────────────────────── 📋 填报区 ─────────────────────────────────
```

### 3. 附件4 折叠卡片

```
▼ 附件4：公开招聘工作人员基本情况表 — 2025年柳州教育局招聘（第一批）
  计划 5人  │  已办理 1人  │  本次 4人  │  暂缓 0人
┌──────────────────────────────────────────────────────────┐
│  ...（展开的表格和表单内容）                                │
└──────────────────────────────────────────────────────────┘

▶ 附件4：公开招聘工作人员基本情况表 — 2025年柳州教育局招聘（第二批）
  计划 3人  │  已办理 0人  │  本次 3人  │  暂缓 0人
```

- 标题栏显示：批次名称 + 一行关键数字摘要
- 多个批次时默认只展开第一个，其余折叠
- 点击标题栏切换展开/折叠
- 折叠状态下审核者一眼看到全局汇总

## 四、对比总结

| 维度 | 改动前 | 改动后 |
|------|--------|--------|
| **结构** | 扁平混杂：岗位卡片+附件4+按钮全堆一起 | 三区分离：填报→汇总→附件 |
| **引导** | 无 | Step Bar 轻量引导 |
| **附件4可见性** | 淹没在岗位卡片末尾 | 独立区域，独立卡片 |
| **附件4密度** | 始终全部展开，很长 | 多批次折叠，摘要可见 |
| **操作逻辑** | 填完→看到附件4→上面还有个"添加岗位"按钮 | 填完→自然滚动到汇总区→上传附件→提交 |
| **代码** | 附件4耦合在 renderRecruitmentForms | 独立 renderBatchSummaries 函数 |
