<!-- ===== 改动说明 ===== -->
<h2 style="font-size:16px;margin-bottom:12px;">改动说明</h2>

<table class="change-table">
  <thead>
    <tr><th>改动项</th><th>当前（table）</th><th>优化后（卡片列表）</th></tr>
  </thead>
  <tbody>
    <tr>
      <td><strong>布局结构</strong></td>
      <td><code>&lt;table&gt;</code> 五列表格，固定列宽，长身份证号换行</td>
      <td><code>&lt;div&gt;</code> 卡片列表，每人一张卡片，信息分层展示</td>
    </tr>
    <tr>
      <td><strong>姓名</strong></td>
      <td>表格第一列纯文本</td>
      <td>带头像圆圈（取姓氏首字），更有人情味</td>
    </tr>
    <tr>
      <td><strong>编制类型</strong></td>
      <td>表格列中的 badge</td>
      <td>紧贴姓名右侧，作为身份标签</td>
    </tr>
    <tr>
      <td><strong>跨校状态</strong></td>
      <td>表格最后一列，信息拥挤</td>
      <td>跨校人员：类型标签 + 任职学校在姓名同行，时间在卡片右侧<br>非跨校人员：不显示，无视觉干扰</td>
    </tr>
    <tr>
      <td><strong>身份证号 + 入编方式</strong></td>
      <td>各占一列</td>
      <td>合并到卡片第二行，用竖线分隔，信息紧凑</td>
    </tr>
    <tr>
      <td><strong>视觉层次</strong></td>
      <td>表头 + 斑马纹行，Excel 风格</td>
      <td>圆角卡片 + hover 微交互，现代 UI 风格</td>
    </tr>
    <tr>
      <td><strong>跨校信息可读性</strong></td>
      <td>类型标签+学校+日期挤在一列，难以扫读</td>
      <td>类型标签+学校在姓名行（主视线），日期在卡片右侧（次要信息）</td>
    </tr>
  </tbody>
</table>

<!-- ===== 注意 ===== -->
<div class="anno" style="margin-top:20px;">
  <strong>设计原则：</strong><br>
  · 待完善（incomplete）面板保持现有 table 布局不变，因为它字段少（姓名/编制类型/身份证号/入编方式），table 够用<br>
  · 仅"已匹配"面板去表格化，因为它已增加到 5 列且跨校信息需要更好的展示空间<br>
  · 卡片布局天然适配不同长度内容（身份证号/学校名），不再有列宽对齐问题<br>
  · 跨校人员信息更突出——类型标签紧贴姓名，一眼就能区分
