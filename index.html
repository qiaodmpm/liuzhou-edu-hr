AI Frontend Project Template

一个可直接进入 GitLab、云效、Harbor 和 K8s 发布链路的最小前端项目模板。

这个模板用于新项目初始化。它默认提供一个可构建的静态首页、容器化能力和 K8s 发布所需清单， 让新仓库在创建后即可进入测试环境自动化部署流程。

Build Ready

执行 `npm run build` 后会输出 `dist/`，可直接用于容器镜像打包。

Container Ready

内置 `Dockerfile` 和 `nginx.conf`，适合静态资源前端镜像发布。

K8s Ready

内置 Deployment / Service / Ingress 模板，通过环境变量替换实现动态服务发布，并映射到 `${SERVICE_NAME}.cicd.chaodao.cn`。
